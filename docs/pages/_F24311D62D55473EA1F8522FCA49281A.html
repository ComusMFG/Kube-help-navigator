Toolbar

Some of the commands for manipulating viewports are accessible through buttons from the toolbar. All of them are also accessible by shortcut keys, and commands for switching mouse modes are accessible via the viewport context menu. The toolbar can be shown or hidden depending on the Toolbar option of the View menu.

There exist several types of toolbars:

  • limited - it appears when opening KUBE and no data file is created or opened.

  • full - it appears when there is a new or existing files opened in KUBE.

  • macro speedbar - appears only when the option Show Macro Speedbar in View menu is enabled

  • optional buttons - appears in both limited and/or full toolbars depending on the KUBE settings.

Note: Incorrect ToolTip Text Is Displayed.
When you move the mouse pointer over toolbar buttons to view the ToolTips for each button, you may see the text from the previous ToolTip in a new ToolTip box. This is a common problem for all applications running under Windows XP. For more information about this issue, please refer to http://support.microsoft.com/?id=814135.
