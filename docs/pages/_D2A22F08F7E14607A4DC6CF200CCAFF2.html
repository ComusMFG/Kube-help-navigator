Preferences - Display - General

General Group

Display scroll bars

If you need more space in the viewport, uncheck this option to hide the scroll bars. This will take effect after you restart KUBE.

Display progress bar when drawing

After every action on the viewport (rotate, pan, zoom, select, hide, show, etc.) a red progress line will be drawn on the KUBE status bar. Uncheck this option to disable progress bar.

WorkSpace

This option sets the visibility of the WorkSpace panel. It is equivalent to calling the Display WorkSpace command.

Include transformations in Zoom All

This option sets whether the visible transformations to be used in calculating the maximum extents of the scene when calling the Zoom All command.

OpenGL group

Double buffered

If your video card supports double buffering, check the option to enable this mode. It will considerably increase drawing speed. This option will take effect after you restart KUBE.

Cached display

Caches the last image and the result is a dramatical improve of view refresh in some situations like minimize/maximize, window overlap, displaying a dialog, etc. This option will take effect after you restart KUBE.

Overwrite Shading on Load group

No change

Objects will be displayed with their custom shading when loaded from file.

Flat

Objects will be displayed with Flat shading when loaded from file.

Flat + Wireframe

Objects will be displayed with Flat + Wireframe shading when loaded from file.

Smooth

Objects will be displayed with Smooth shading when loaded from file.

Smooth + Wireframe

Objects will be displayed with Smooth + Wireframe shading when loaded from file.

Inspection mode rendering group

Reference opacity slider

Sets the transparency of the reference displayed in Inspection mode. Default level is 50% (middle of the slider). Transparency is 100% when position is on the right hand side of the slider. Transparency is 1% when the position is  on left hand side of the slider.
