Rendering Smooth and Smooth Mode

Rendering Smooth is accessible from the tree context menu > Rendering > Smooth.

Smooth Shaded mode is accessible from the viewport context menu > Render Mode > Smooth or by pressing 6.

Description: These commands affect visual representation of scan data and meshes only. When in this mode, KUBE draws objects as smooth shaded surface. Shading is the same as in Flat Mode, but there is an approximation of the hue between neighbouring triangles.

Rendering Smooth is applied to a particular entity (or group of entities) from which the context menu was called.

Smooth mode is applied to all scan data and meshes in the scene.

Example

To switch between Smooth and Smooth + Wireframe modes use Toggle Wireframe command.
