Hardware Settings - Real Time Processing Tab

Description: Real Time Processing tab allows changes in processing options during scanning.

Profiles

 

Maximum point spacing

'Between stripes' option

Specifies the distance between stripes. Enter a number in mm. Default value is 5mm.

'Between points on the same stripe' option

Specifies the distance between points within a stripe. Enter a number in mm. Default value is 2mm.

 

Linear (1D) sampling

'Use one point in'  box

Defines how many of the points obtained while scanning, are used. If the value entered is 1, every point on the stripe will be used, if the value is 2, every second point on each stripe is used. Default value is 1.

Linear sampling is disabled by default.

Scanning speed

Choose the scanning speed. Options depends on the series of sensor to be used:

For C series: 15Hz and 30 Hz

 

Certified Settings checkbox

When this option is enabled all settings in the tab are set to their default values. For the best results, it is recommended to use 'Certified settings'.

When all changes are made, confirm with Apply button.
