SURFA PCI

Description: SURFA PCI Board is an image processing board. SURFA PCI is a very important part of the scanning system. It ensures the connection between the PC and the ModelMaker system, allowing control and fast, accurate data acquisition.

 

The boards can be easily damaged (by static electricity for example), please treat it with care.

Make sure that none of the electrical components on the board or the underside of the board are touched, where the component legs go through. When the board is not in the PC, make sure that it is kept in its anti-static bag. When mounting the card in the PC, please wear anti-static bracelet.

The card should be mounted in the PC by an authorised person only!

The device installation and set-up are done automatically by KUBE software.
