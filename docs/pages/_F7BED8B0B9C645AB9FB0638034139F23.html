Front-Facing Mode Selection

This command is accessible from Select > Front-Facing Mode or by pressing Frontselection button on the toolbar.

Description: When this mode is enabled, all shape selections will select only the scan data and mesh triangles, which normals face front towards the viewport. Selecting entities of other types is not affected. Exit this mode by pressing on the toolbar icon again.

 

Front-Facing mode selection is mainly used when there are rear surfaces facing backwards to the surface you want to select. When there are rear surfaces facing front to the viewport, they are also selected.
