Export Entities

The properties of all visible entities in KUBE can be exported in CSV (comma-separated) file format, which can be read by any spreadsheet software (like Microsoft Excel, OpenOffice, etc.) or other statistical software. Formatting of the data is set-up from the Preferences > CSV File Export dialog. KUBE uses the decimal symbol defined in Windows Regional Settings.

The exported file contains the following information:

Common Section:

FileName, String
Created, Date (in format of the current system settings)
Modified, Date (in format of the current system settings)
ReportDate, Date (in format of the current system settings)

Operator, String
Object Name, String
Object No, String
Software, String (name & version)
Localiser Type, String
Localiser Version, String (BIOS version)
Localiser S/N, String
Sensor Type, String
Sensor S/N, String
Length Units, Enum (one of: meter, decimeter, centimeter, millimeter, micrometer, yard, foot, inch, point)
Angle Units, Enum (one of: degree, radian, grad)
Angle Units Decimal, Yes/No (always Yes when AngleUnits=radian)
RoundSlotLength, Enum (one of: Full Length, Centre-to-Centre)
Comments, String
CurrentCS, String (World Coord Sys (WCS) or name_of_transformation)
 

Entities Table Section:

Mesh_Name, Type, Group, IsLocked, Extents(MinX, MaxX, MinY MaxY, MinZ, MaxZ), Size(X, Y, Z), NumPoints, NumTriangles, Colour(R, G, B)
ScanData_Name, Type, Group, IsLocked, Extents(MinX, MaxX, MinY MaxY, MinZ, MaxZ), Size(X, Y, Z), NumPoints, NumStripes, NumPatches, Colour(R, G, B)
ProbePoints_Name, Type, Group, IsLocked, Extents(MinX, MaxX, MinY MaxY, MinZ, MaxZ), Size(X, Y, Z), NumPoints, Colour(R, G, B)
PointCloud_Name, Type, Group, IsLocked, Extents(MinX, MaxX, MinY MaxY, MinZ, MaxZ), Size(X, Y, Z), NumPoints, Colour(R, G, B)
Polyline_Name, Type, Group, IsLocked, Extents(MinX, MaxX, MinY MaxY, MinZ, MaxZ), Size(X, Y, Z), NumPoints, Colour(R, G, B)
Point_Name, Type, Group, IsLocked, Extents(MinX, MaxX, MinY MaxY, MinZ, MaxZ), Size(X, Y, Z), Centre(X, Y, Z), Colour(R, G, B)
Line_Name, Type, Group, IsLocked, Extents(MinX, MaxX, MinY MaxY, MinZ, MaxZ), Size(X, Y, Z), Centre(X, Y, Z)- mid point, Orientation(I, J, K)- tangent, StartPoint (X, Y, Z), EndPoint (X, Y, Z), Length, Colour(R, G, B)
Plane_Name, Type, Group, IsLocked, Extents(MinX, MaxX, MinY MaxY, MinZ, MaxZ), Size(X, Y, Z), Centre(X, Y, Z), Point (X, Y, Z), Orientation(I, J, K) - normal, Offset, Colour(R, G, B)
Cylinder_Name, Type, Group, IsLocked, Extents(MinX, MaxX, MinY MaxY, MinZ, MaxZ), Size(X, Y, Z), Centre(X, Y, Z)- mid point, Orientation(I, J, K)- axis, StartPoint (X, Y, Z), EndPoint (X, Y, Z), Length- axis length, Radius, Perimeter- base circumference, Area, LateralArea, BaseArea, Volume, Colour(R, G, B)
Sphere_Name, Type, Group, IsLocked, Extents(MinX, MaxX, MinY MaxY, MinZ, MaxZ), Size(X, Y, Z), Centre(X, Y, Z), Radius, Perimeter- equator circumference, Area, Volume, Colour(R, G, B)
Circle_Name, Type, Group, IsLocked, Extents(MinX, MaxX, MinY MaxY, MinZ, MaxZ), Size(X, Y, Z), Centre(X, Y, Z), Orientation(I, J, K)- plane normal, Radius, Perimeter- circumference, Area, Colour(R, G, B)
Cone_Name, Type, Group, IsLocked, Extents(MinX, MaxX, MinY MaxY, MinZ, MaxZ), Size(X, Y, Z), Orientation(I, J, K)- axis, StartPoint(X, Y, Z)- apex, EndPoint(X, Y, Z)- base, Length- axis length, Radius, Perimeter- base circumference, SlantLength, Angle, SlantAngle, Area, LateralArea, BaseArea, Volume, Colour(R, G, B)
RectangularSlot_Name, Type, Group, IsLocked, Extents(MinX, MaxX, MinY MaxY, MinZ, MaxZ), Size(X, Y, Z), Centre(X, Y, Z), Orientation(I, J, K)- plane normal, Length, Radius/Width- width, Perimeter, Area, Colour(R, G, B)
RoundSlot_Name, Type, Group, IsLocked, Extents(MinX, MaxX, MinY MaxY, MinZ, MaxZ), Size(X, Y, Z), Centre(X, Y, Z), Orientation(I, J, K)- plane normal, Length, Radius/Width- radius, Perimeter, Area, Colour(R, G, B)
ViewPosition_Name, Type, Group, Centre(X, Y, Z)- view point, Axis(I, J, K)- direction, Matrix(a11, a12, a13, t1, a21, a22, a23, t2, a31, a32, a33, t3)
Transformation_Name, Type, Group, Centre(X, Y, Z)- origin/offset from the WCS origin, Axis(I, J, K) - Z axis direction, Matrix(a11, a12, a13, t1, a21, a22, a23, t2, a31, a32, a33, t3)

Column titles and description of Entities Table Section:

EntityName - name of the entity (String)
Type - type of the entity (Enum(one of: Mesh, Scan Data, Probe points, Point cloud, Polyline, Polyline, Polyline, Polyline, Polyline, Polyline, Point, Line, Plane, Cylinder, Sphere, Circle, Cone, Rectangular slot, Round slot, Viewport, Transformation))
Group - name of the group, which the entity belongs to (String)
IsLocked - locked status of the entity (Yes/No)
Extents(MinX, MaxX, MinY, MaxY, MinZ, MaxZ) - XYZ extents of the entity (6 x Float)
Size(X, Y, Z) - XYZ size of the entity (3 x Float)
Centre(X, Y, Z) - centre of XYZ extents of the entity (3 x Float)
Orientation(I, J, K) - direction of line, cylinder axis, cone axis; normal of plane, rectangular/round slot; orientation of viewport, transformation (3 x Float (IJK = -1.0 ... +1.0))
Axis(I, J, K) - axis of rectangular/round slot (3 x Float(IJK = -1.0 ... +1.0))
StartPoint(X, Y, Z) - first point of line, cylinder axis, cone axis (apex) (3 x Float)
EndPoint(X, Y, Z) - second point of line, cylinder axis, cone axis (base centre) (3 x Float)
Length - length of line, cylinder axis, cone axis, rectangular/round slot (Float)
Radius/Width - radius of circle, sphere, cylinder, cone, round slot (could be full length or centre-to-centre); half width of rectangular slot (Float)
Perimeter - circumference of circle, cylinder base, cone base; perimeter of rectangular/round slot (Float)
Offset - offset of plane, circle plane, rectangular/round slot plane from the origin (Float)
SlantLength - slant length of cone (Float)
Angle - apex angle of cone (Float/String(XXdXXmXX.XXXXs degrees, XXgXXcXX.XXXXcc grads))
SlantAngle - slant angle of cone (Float/String (XXdXXmXX.XXXXs degrees, XXgXXcXX.XXXXcc grads))
Area - area of circle, rectangular/round slot, sphere; full area of cylinder, cone (Float)
LateralArea - lateral area of cylinder, cone (Float)
BaseArea - base area of cylinder, cone (Float)
Volume - volume of sphere, cylinder, cone (Float)
Matrix(A11, A12, A13, T1, A21, A22, A23, T2, A31, A32, A33, T3) - transformation matrix of viewport, transformation (12 x Float (Aij = -1.0 ... + 1.0))
NumPoints - number of vertices of scan data, mesh, point cloud, probe points, polyline entity (Integer)
NumTriangles - number of triangles of scan data, mesh entity (Integer)
NumStripes - number of stripes of scan data entity (Integer)
Colour(Red, Green, Blue) - RGB colour of the entity (with exception of viewports and transformations) in decimal format (3 x Integer)
 

Dimensions Table Section:

DimensionNumber, Point1(X, Y, Z), Point2(X, Y, Z), 1D(X, Y, Z), 2D(XY, YZ, ZX), 3D(XYZ)

 

Column titles and description of Dimensions Table Section:

DimensionNumber - consecutive number of the dimension (Integer)
Point1(X, Y, Z) - co-ordinates of the first point (3 x Float)
Point2(X, Y, Z) - co-ordinates of the second point (3 x Float)
1D(X, Y, Z) - distance between the two points projected on OX, OY, and OZ axis (3 x Float)
2D(XY, YZ, ZX) - distance between the two points projected on OXY, OYZ, and OZX planes (3 x Float)
3D(XYZ) - distance between the two points in 3D space (Float)
 

Gap and Flush Table Section:

Gap&FlushNumber, Point1(X, Y, Z), Point2(X, Y, Z), Direction(I, J, K), Point3(X, Y, Z), Value

Column titles and description of Gap and Flush Table Section:

Gap&FlushNumber - consecutive number of the Gap & Flush dimension (Integer)
Point1(X, Y, Z) - co-ordinates of the first point (3 x Float)
Point2(X, Y, Z) - co-ordinates of the second point (3 x Float)
Direction(I, J, K) - direction of the line defined by Point1 and Point2 (3 x Float (IJK = -1.0 ... +1.0))
Point3(X, Y, Z) - co-ordinates of the third point (3 x Float)
Value - value of Gap and Flush dimension, e.g. 3D distance from Point3 to the line defined by Point1 and Point2 (Float)
