Subdivide

This command is accessible from Mesh > Subdivide or by pressing Ctrl + U.

Description: Subdivide command subdivides larger triangles within the visible selected area into smaller ones. This command is grayed if there is no selection or all selections are hidden. It works on wholly selected entities as well as on partial selections.

Target maximum edge length

Average of whole mesh

Maximum edge length will be based on the average edge length of the whole mesh.

Average of selected area

Maximum edge length will be based on the average edge length of the selected area.

mm

Maximum edge length will be based on the given value.

Decimate thin triangles

Removes thin triangles, i.e. that have an angle less than the 20 degrees.

Subdivide command increases the polygon count in the region, and is useful for operations such as Average Noise Reduction, Noise Reduction By Curvature, Enhance Features, Smooth Boundaries, etc.
