Combine Selected Entities

This command is accessible from Edit > Combine Selected Entities.

Description: Combine Selected Entities command combines all visible selected entities of one type into single entity of the same type. It is grayed if there is no selection or it is not visible. It is applicable to compound entities scan data, meshes, point clouds, and polylines. Datum entities are not affected.

If you have few scan data, mesh, and point clouds selected, all these scan data entities will be combined into one entity, all these meshes will be combined into one mesh entity, and all point clouds will be combined into one point cloud entity. The name of the combined entity will be identical with the name of the lowest selected entity in the tree hierarchy.

In the case of polylines, all selected polylines will be combined into single polyline. It will be located in the highest group in the tree hierarchy and its name will be identical with the name of the highest polyline. If whole polyline groups are selected, they are combined into single group following the same rules for naming.

Note that this command does not change the geometry of the entities it just rearranges their structure in the Entities pane.
