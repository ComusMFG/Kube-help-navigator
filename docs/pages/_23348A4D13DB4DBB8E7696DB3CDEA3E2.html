Create Viewport Entity

This command is accessible from View > Custom Views > Create Viewport Entity or by pressing Ctrl+Shift+V.

Description: This command creates an entity, which stores the current viewport orientation.

This entity is of type Viewport and is located in View Position group. It is not graphically represented in the scene; its appearance is in the Entities pane only.

Viewport entity can be reselected at any time to restore the view - right click on the viewport name and select Use from the tree context menu.

If you select Set to Current View, you will change the viewport orientation to the current one.

Other commands from this menu are:

  • Select/Unselect for selecting and deselecting viewport entity.

  • Rename for renaming viewport entity.

  • Delete for deleting viewport entity.

  • Properties for displaying viewport entity properties.
