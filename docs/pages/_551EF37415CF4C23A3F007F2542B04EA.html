New Circle - Non-Interactive

This command is accessible from Datuming > Non-Interactive > Circle.

Description:New Circle command creates new datum circle by one of the following methods:

Methods:

Plane and Normal: 

Name

Name for the circle. The default name is Circle N, where N is the number of the subsequent newly created datum circle.

Point

Select an existing datum point, sphere, or circle from the list to define the centre of the circle or type-in the co-ordinates of the centre manually.

Radius

Radius of the circle. It must be a positive non-zero value.

Normal

Select an existing datum cylinder, line, or plane to define the plane where the circle will lay or type-in the co-ordinates of the normal manually.

Best Fit:

From list

Selects datum points, spheres, and circles from the list.

  •  Add >>button select datum points, spheres, and circles from the left hand list and press the button to add them to the right hand list.

  • << Removebutton select datum points, spheres, and circles from the right hand list and press the button to remove them from this list. Then the removed entities are automatically placed in the left hand list.

From selection

Select all visible and selected datum points, spheres, and circles.

RESULT: When all necessary entities are selected from the lists, the result, which contains the co-ordinates of the centre, co-ordinates of the plane normal, and the radius of the circle, is displayed.

All entities from the right hand list are used for creation of the point. Datum circle is fitted using of the co-ordinates of the selected entities. In case of spheres and circles, their centres are used.

Note: You need to select at least three entities from the list or to have at least three selected and visible entities if you choose From selection option.
