Area [2D] Sampling

This command is accessible from Scan Data > Sampling > Area [ 2D ].

Description: Area Sampling command samples the visible selected scan data patch by patch. It works on entire entity, no matter if the scans are selected wholly or partially KUBE will issue a warning message about this and will offer you to save the file before proceeding.

A rectangular array of points is calculated for each patch. You can specify the spacing between points in U and V directions on the plane fitted for every patch. The resulting data is in scan data format. This command is grayed if there is no selection or all selections are hidden.

U sample distance in mm. Default value is 1mm.

V sample distance in mm. Default value is 1mm.
