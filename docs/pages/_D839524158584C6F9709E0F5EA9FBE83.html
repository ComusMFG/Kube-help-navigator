Interactive Datum Interface Description

The mode Create Datum allows interactive definition of 9 datum types by different methods. The mode is displayed in a separated pane and the user can pass from one datum type creation to another simply by switching between datum tabs. Using this mode can be created new datums or can be changed properties of existing ones.

The Create Datum pane contains the following sections:

1. Nine tabs for switching between different datum types:

point, line, plane, sphere, cylinder, circle, cone, rectangular slot, and round slot.

2. Method section for choosing the most appropriate way to define the requested datum.

3. Section for construction entity definition used for interactive definition of each datum component for the current method.

4. Result section - used to set a name for the new datum and to preview its properties.

 

Method Section

For each datum type are available several construction methods, the Interactive one is selected by default.

If the creation method requires more than one component definition, then each definition is separated in a tab, as shown below. Each tab has a small icon showing the entity type, that will be defined. This icon is:

  • grayed if no value is set in the definition tab (example with plane icon: )

  • coloured if the component is completely defined (example with plane icon: ).

When the temporary construction entity is defined in the first tab (all values are filled in the fields), then the second definition tab will be automatically activated. This is valid for all definition methods, except manual coordinates input.

Particularities:

First tab is always selected by default

For each datum definition a method is automatically selected using the following rule:

  • Pick from viewport method is enabled by default only the first time you chose a method.

  • If the user changes the definition method, his last choice will be set as default when switching to another component definition (to another tab) in the terms of the same method.

If the construction entity in a method can use more than 1 datum type, then a specific button is added (see on left and below) to facilitate the datum selection.

 

The last option "Pick from screen" in this list allows the user to pick an entity from the viewport. If this option is enabled, then the user can simultaneously select entity type and define its values. It is used for quick definition by picking predefined datums from the viewport. By default this option is disabled and each primitive must be defined by any of the available methods.

Notes: All methods for each datum entity are explained in details in the correspondent chapters (for example: all methods for point creation are presented in the New Point section).

 

Section for construction entity definition

The definition dialog shown in this section depends on the construction entity required by the current method. Each datum definition can be set by 4 main methods:

  1. Capture delayed operation. It will start when all construction datums (if the method requires more than1) are set and Create is initiated. The datums will be captured by their order in the method description. The capturing functionality is the same as in the arm menu.

  1. Fit selected / Detect interactive method for setting values. The user makes a selection, press the 'Fit selected' button (for point) or 'Detect' button for the other datum entities and the datum parameters will be instantly filled in the edit boxes. If necessary these values can be manually changed.

  2. Choose from list or pick entity both options refer to the same functionality selection of an existing primitive, co-ordinate axis or plane. The user can either choose a datum from the list or directly pick it on the viewport. The datum parameters will be instantly filled in the edit boxes. If necessary these values can be manually changed. The Pick Entity button is enabled by default.

  3. Manual co-ordinates input or pick points both options refer to the same functionality simple co-ordinate input. The user can either type manually the datum parameters in the edit boxes or pick a minimal number of points on the viewport to define the datum. The minimal number of picked points depends on the entity type.

Note: If you want to use Pick points method for datum definition and at the same time you have an active selection mode, you should first exit the selection mode by using the key Esc and KUBE will pass automatically to the Pick points mode

When a construction entity has all parameters filled, then it is immediately visualised in the viewport as temporary entity.

Result section

When the values are set for all construction entities, the fields in the result section will be filled and the new datum will be visualised in the viewport as final construction entity. The user can accept it, can change some of the values or cancel the datum creation.

  • In case of canceling datum creation, simply press the Close button  - the temporary visualised construction and result datums will disappear from the screen and the datum creation mode will be closed.

  • In case of changing datum values, the user should go to the definition section and make the necessary corrections. The temporary visualised construction and result datums will be updated instantly to reflect the last changes.

Note: For datums having normal or direction (as plane, circle, line, cylinder, cone, or slots) there is a small button in the result section allowing flipping the normal of the result entity.

  • In case of accepting the datum creation, it remains only to choose a name for the new datum.

Name you have 3 choices for setting the datum name: leave the default one, type a new name or choose an existing one from the list. The default name is Datum N, where Datum is the datum type (point, circle, etc.) and N is the number of the subsequent newly created datum. When a datum is created the number N in the name will automatically increase.

For example: when the datum "Point 2" is created, the name will be automatically changed to "Point 3" to be ready for next point creation.

When ready press the Create button. The result construction datum becomes a real datum and appears in solid colour (as set in Display settings). If the datum can not be created due to incorrect input parameters, then the Create button will remain inactive.

If you want to exit the transformation mode, then press the Close button.
