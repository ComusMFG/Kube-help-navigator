Capture 2D Line

Description: Capture 2D Line allows a compensated datum line to be captured using the localiser probe. It is used to get edges on the object. Another application of this command is to build datum alignments from point, line, and plane. This command is accessible from the Localiser Menu Datum > 2D Line.

You will need a plane where the line will be projected. KUBE offers two options:

  • to capture a plane.

  • to use an existing plane or plane reducible entity. If there are existing planes, circles, cylinders, cones, or slots the following dialogue will appear when Datum 2D Line is selected from the localiser menu:

If the Capture 3 or more points to define a plane option is selected, the Capture Plane procedure will start. If one of the existing planes from the list is selected, it will be used for the base of the line. If there are no existing planes, this dialogue is omitted and the procedure will start immediately to capture a plane.

Note: If Always capture method is used then no dialog for selecting existing plane reducible entities appears but Capture Plane procedure will automatically start. See System > Preferences > Datums > Capture Method (Base Plane Definition) for details.

Capture 2D Line Wizard

  • When the base plane is captured or selected, capture the points that define the line:

  • Press 'B' button at least two times to collect the necessary points. Hold 'B' button to delete the last captured point if necessary. Press 'A'button to finish.

A line cannot be created if you captured less than two points. In this case a warning message will appear.

Captured points are projected on the base plane. If more than two points are captured, KUBE will fit a line from the set of the projected points, otherwise the two projected points will be used to construct the line. Then the line is offset on the base plane depending on the orientation of the probe during capture.

The following information about the resulting 2D line will be displayed:

  • normal of the line.

  • RMS of the fitting (RMS will be zero if you captured two points only).

Example

  • Press 'A'button to reject the resulting 2D line or 'B'button to create it

After finishing the capture procedure, KUBE will issue a dialog, asking you if you will continue capturing 2D lines.

Example

  • Press 'A' button to exit the capture mode or 'B'button to continue capturing.
