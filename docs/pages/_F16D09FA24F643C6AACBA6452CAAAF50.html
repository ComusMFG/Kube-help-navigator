Repair

This command is accessible from Mesh > Repair or by pressing Ctrl + R.

Description: Repair command is a combination of two functions: Remove Faulty Areas and Fill afterwards using their default parameters. This command is grayed if there is no selection or all selections are hidden. It works on wholly selected entities as well as on partial selections.
