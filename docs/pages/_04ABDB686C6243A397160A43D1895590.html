Radial Cross Sections

This command is accessible from Polylines > Cross Sections > Radial.

Description: Radial Cross Sections command creates a number of radial cross sections through the visible selection. In this method the sections are arranged in a circle around a user defined centre point. The angular separation between the planes and the inner and outer radii of the circles enclosing them can also be set. You can use points from scan data and meshes only. All polylines created by this method will be placed in separate group called Section 0.

Radial Cross Sections command is grayed if there are no scan data or mesh selections or all selections are hidden. It works on wholly selected entities as well as on partial selections. In case of partial selection only those parts of polylines are extracted that are within the selection although the parameters are calculated for all objects with selections. 

Cross sections:

  • Angle section spacing in degrees. Default value is 10 degrees.

  • Width section width. This parameter is calculated automatically and is based on the size of the object in both horizontal and vertical direction from the current view.

  • X radius radius of the inner circle (ellipse) in the horizontal direction. Default value is 1mm.

  • Y radius radius of the inner circle (ellipse) in the vertical direction. Default value is 1mm.

  • Lock radii maintains a constant ratio between the X and Y radii when some of them is changed. It is enabled by default.

Starting parameters:

  • Starting point: X, Y, Z pick a point from the screen or type-in the co-ordinates of the centre of the sectioning. These parameters are calculated automatically and are based on the parameters from Cross section group and current orientation of the viewport.

  • Direction: X, Y, Z pick a line/normal/axis from the screen or type-in the normal of the plane where the starting section lays. These parameters are calculated automatically and are based on the parameters from Cross section group and current orientation of the viewport.

Extract parameters:

  • Tolerancing chordal tolerance. This is the maximum error tolerance for polyline deviation from the original profile of the data. See Chordal Tolerancing for details. Default value is 0.001mm. 

  • Weld distance below which sections will be welded together. This will form continuous sections, for example, on patch boundaries where the scan data does not overlap perfectly. Default value is 0.1mm.

Example

Align:

  • Reference select a reference object for aligning (viewport, world, plane, or plane reducible entity). Then use X, Y, or Z buttons to choose the direction. For datum entities Z button always defines section plane parallel to the plane where the entity lie.

If a datum entity is selected as reference it should be close to the object from, which radial polylines will be extracted. In this case the extraction extents are defined by the datum.

  • Direction

    • X X-axis along which the radial polylines will be aligned.

    • Y Y-axis along which the radial polylines will be aligned.

    • Z Z-axis along which the radial polylines will be aligned.

See Scroll Bars for explanation of the viewport axes.

Buttons:

  • Extract extracts the polylines as separate entities according to the current axis and settings.

  • Close closes this dialog.

You may freely rotate, pan, and zoom the viewport while Cross Section - Radial dialog is open. You may also change the selection, delete, and perform other visualisation commands.

Each polyline section has the same colour as its original mesh. If you have more than two meshes with different colours, then their correspondent polylines can be easily recognised. Anyway, if you have more than one polyline section on a single mesh, you may paint each section in different colour in order to distinguish them.

Use Radial Cross Sections to create sections from point data for export to a CAD or other computer system. This sectioning is normally used to extract polylines from circular objects such as wheel trims.
