Annotation Context Menu

This menu appears when user right clicks with the mouse on a annotation in Edit annotation mode only. Most of the commands are accessible also via the Annotations Menu. The context menu contains the following commands:

 

 

Delete annotation deletes the annotation pointed by the mouse.

Edit ...:

Launches the settings dialog for annotation. If Format annotations command called from main menu it affects all annotations, if called from annotations Context Menu it affects current annotation only.

Delete All deletes all annotations from the current page.
