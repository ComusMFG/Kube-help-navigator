labeling

The Labeling mode command is accessible from Measure > Labeling or by pressing Labeling mode button in the toolbar.

Description: This command switches the mode for creating and editing labels for datums and points of compound entities. In this mode a context menu appears when pointing on a label with the RMB, offering all functions associated to the label editing.

The cursor changes to label tool . Click on a datum or a point from compound entity (scan data, mesh, point cloud, probe points, polyline), in which you're interested, and move the mouse cursor to the position where you want to create a label. On the picture below there are labels, where all available information for the particular entity/point is shown.

Labels example

Labels consist of the name of the entity assigned to it and the properties of that entity. Labels picked from points that belong to compound entities have only their co-ordinates, i.e. no name appears on top.

Labels have background colour same as the colour of the picked entity. For points from compound entities the background is always white. The information displayed on the labels depends on the particular entity.

Labels can be created for datum entities from the Entities tree. Mark one or more (using Ctrl or Shift buttons) entities. Right-click and from the context menu select Put Label command. Labels are automatically created for the marked entities. If you call this command from the context menu of the Datuming group labels will be created for all datum entities in the scene.

When you pass over an existing label the cursor changes its shape to To modify label's position, just click on it and drag the label to the position you want.

Move label example

Labels can be formatted individually or all at once. To format individual label right-click on it and from the context menu select Format command. To format all labels go to Preferences > Display > Labels dialog.

Labels can be deleted individually or all at once. To delete individual label right-click on it and from the context menu select Delete Label command. To delete all labels in the scene right-click on a label and from the context menu select Delete All Labels command or go to Measure menu and select the same command from there. To delete labels from the Entities tree, mark the desired datum entities, right-click and from the context menu select Remove Label command.

When rotate the scene labels are always orientated parallel to the viewport plane and the distance between the entity and the label remains the same.

Note 1: More that one label can be created for an entity.
Note 2: When a labeled entity is hid then all labels assigned to it are also hid.

Labels and their positions are stored in the sab2 file so next time you open it all created labels appear. Formatting is not stored so when you open the file, the labels will be formatted with their default settings.
