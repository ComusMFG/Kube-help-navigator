Merge

Description: Merges the selected scan data and produces mesh.

Parameters:

PtScp point spacing, i.e. lower bound for distance between points.

AreaSmp sets whether to use area sampling before merge or not. Available options are Yes and No.

AreaSmpDist UV sample distance for area sampling.

OptScan sets whether to use patch optimisation before merge or not. Available options are Yes and No.

OptScanDist limit of the patches offset from their original position.

OptScanPtSmp - sets the sampling value during scan optimisation.

PolygonRed sets whether to use polygon reduction after merge or not. Available options are Yes and No.

PolygonRedSpc decimation tolerance.

InclBndPt sets whether to keep all boundary points so that the result mesh to have exactly the same shape as the scan data or not. Available options are Yes and No.

EnhanceFeatures sets whether to enable enhancing features on areas detected as high curvature, i.e. edges, or not. Available options are Yes and No.

Sensor sets the sensor type, which affects the other options.

UI Commands:

Scan Data > Merge from the main menu.

Example:

Merge( PtSpc=0.500, AreaSmp=Yes, AreaSmpDist=0.500, OptScan=Yes, OptScanDist=1.000, OptScanPtSmp=2, PolygonRed=Yes, PolygonRedSpc=2.000, InclBndPt=No, EnhanceFeatures=Yes, Sensor="MM Z70" )
