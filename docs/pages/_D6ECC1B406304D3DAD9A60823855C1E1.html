Display Boundaries

Display Boundaries is accessible from the tree context menu > Rendering > Display Boundaries.

Display Boundaries mode command is accessible from the viewport context menu > Render Mode > Display Boundaries or by pressing E.

Description: This command affects the visual representation of all meshes in the scene. When this option is activated, KUBE draws mesh boundaries as connected lines. Display Boundaries is off by default. Boundaries colour can be customised from Preferences / Display / Colours dialog. By default it is light green.

Display Boundaries is applied to a particular mesh (or group of meshes) if it is called from its (their) tree context menu.

Display Boundaries mode is applied to all meshes in the scene if it is called from the viewport context menu.

Changing rendering is not stored, i.e. next time when you open the file the meshes will be displayed in their default modes.
