Preferences - Units

This section allows changing the measurement  units in KUBE.

 

Length Units Group

Select

Choose from the drop-down box the measurement unit for length to be used in KUBE. When selected all dialog and info boxes in the software will show the metric information recalculated in the chosen unit. Default unit for length is mm. If you need some special unit to be defined, select Custom from the list.

Custom

Type the name of the new length unit in the first edit box. Select the most appropriate measurement unit from the drop-down list and type the correspondent ratio between the predefined and the new length units.

Angle Units

Select

Choose from the drop-down box the measurement unit for angle to be used in KUBE. When selected all dialog and info boxes in the software will show the metric information recalculated in the chosen unit. Default unit for angle is deg. If you need some special unit to be defined, select Custom from the list.

Custom

Type the name of the new angle unit in the first edit box. Select the most appropriate measurement unit from the drop-down list and type the correspondent ratio between the predefined and the new angle units.

Display Current Units in

This group defines where the current measurement units to be displayed. There are two available options:

Status bar

This option is selected by default. The current units will be shown in the status bar when the KUBE software is started.

Viewport

If this option is enabled, the current units will be shown as label at the top right corner of the viewport.

Example

Note: When you switch to another length or angle unit, all dialogs that display metric information will be updated to reflect the changes.
Pay attention when entering certified distances during alignment or typing other predefined values.
When exporting data to other formats, please make sure you have selected the most appropriate units.
