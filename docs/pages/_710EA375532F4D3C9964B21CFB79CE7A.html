Handling the ModelMaker sensor

ModelMaker is a precision optical measuring instrument, please treat it with care.

The ModelMaker sensor has been designed to withstand a typical shop-floor environment, nevertheless, there are certain precautions that should be taken when using the sensor:

  • Do not drop the sensor.

  • Do not touch the optical windows on the front of the sensor.

  • Do not attempt to dismantle the sensor. Doing so will invalidate the  warranty.

  • Do not allow the sensor to be covered in any liquid

  • Do not expose the sensor to extremes of temperatures

Laser light is emitted from the indicated aperture - do not look directly into the beam or view with an optical instrument.

ModelMaker hardware set-up

  1. If not already completed, the first step is to set up the localiser

  2. Power up the localiser before starting the ModelMaker hardware set-up.

 

Mounting the sensor on FARO USB Localisers

Mount the sensor to the FARO USB mount.

 

Mount it to the last joint of the localiser and tighten it.

 

Using a CimCore localiser

To be able to use a CimCore localiser with ModelMaker Z, you will need a 85mm probe.
Please contact your CimCore distributor to purchase this item.

 

Mounting sensor on a CimCore localiser

 

Mount the sensor onto the arm mount.

Mount the sensor onto the 85mm CimCore probe

 

Mounting sensor on a FARO Gold/Sterling/Silver localiser

Mount the FARO Gold localiser mount on the end of the localiser.

Mount the sensor onto the localiser mount

 

Connect the sensor cable at the back of the sensor and the trigger cable into the rear of the arm.

Use the releasable velcro fixings to clamp the cables to the arm

 

Installation on Desktop PC

  1. Power down the PC.

  2. Open the PC cover.

Insert the PCI-to-PCI bridge board into any available PCI slot.

Replace the PC cover.

Plug the PCI bridge cable into the PCI-to-PCI bridge board connector.

Depending on the dongle type plug it into the parallel or any available USB port of the PC.

 

ModelMaker Interface Box DL (MMIB-DL)

Connect the sensor cable, trigger cable and the antenna to the front of the MMIB-DL

The trigger cable should only be plugged into the MMIB-DL after the localiser is powered up. 

Connect the power supply cable and the PCI bridge cable to the rear of the MMIB-DL.

Power up the MMIB-DL before powering up the PC

When connecting the power cable, note the locking mechanism on the plug.  Push the plug in and rotate 90 degrees to lock it in place.

Voice control microphone

Note: This feature is unsuitable for use in a noisy environment.

  • A sound card is required to use this feature and Microsoft Speech SDK v5.1 must be installed (provided on the KUBE CD or can be downloaded from www.microsoft.com).

  • A microphone is supplied with the ModelMaker Z system.

Ensure the battery is installed and the microphone switched on.

  • Before using this feature please setup the microphone using Control Panel > Speech on your PC. Select Speech Recognition > Configure microphone and follow the configuration 'wizard'. Experiment with the position of the microphone so it is close to your mouth but not directly in front of it.

 To use voice operation in KUBE click on the speech icon in System > Preferences > Audio.

 In the localiser scan menu, click on the microphone button to enable it.

  • The keywords and commands available are all those words found in the Scan menu e.g. 'Prescan', 'Scan', 'View' etc. During Scan mode: 'Start' to start scanning and 'Stop' to pause.

  • The speech recognition software is developed by Microsoft. Please refer to the Microsoft help files for more information.
