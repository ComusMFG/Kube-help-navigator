Overview

The corrosion inspection functionality is accessible via the Modules menu.

It performs 3 steps of processing:

  1. Merging of raw data,

  2. Corrosion inspection, and

  3. Report printing.

The output of each tasks is the input to the next one (except for the third one). The steps can all be carried out at one go or each step can be performed individually (provided a suitable input file is specified).
