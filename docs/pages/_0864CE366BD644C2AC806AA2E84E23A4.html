Scan Data Menu

The Scan Data menu provides command for capturing, working with scan data. This menu provides also the Merge comand, where the result is a mesh generation.

Scan Data processing commands

Scan Data Processing

Command

Description

Details

Merge

Merges the selected scan data and produces mesh.

 

Linear [1D]

Reduces the size of a data set by removing points from each stripe.

Area [2D]

Samples the data patch by patch. A rectangular array of points is calculated for each patch.

Volume [3D]

 

Fits a cubic grid to the data. In each cube of the grid one point is kept, all other points are discarded. The resulting entity is point cloud.

 

Define XY Grid

Defines XY grid on selected data.

Import XY Grid

Imports existing XY grid as point cloud.

 

Average Noise
Reduction

Reduces noise by applying an average filter.

Median Noise
Reduction

Reduces noise by applying a median filter on each stripe.

Optimise Scan

Reduces the noise in scan data by aligning patches.

Trim Patches

Removes the overlapping points on scan data patches at given overlapping distance.

Invert Normals

Inverts normals of scan data entity, no matter if entirely or partially selected.

Split Scan Data

Splits visible selected scan data into entities containing single patches.
