Hardware Settings - Enhanced Sensor Performance Tab

The Enhanced Sensor Processing tab is available for MMZ, MMD and MMC sensors.

 

Profiles

 

Adaptive Laser Power (DLPC)

When this option is enabled, KUBE will automatically adjust the laser power according to the scanned surface. MM D uses more sophisticated algorithm for adaptive laser power control compared to MM Z. Its name is Dynamic Laser Power Control (DLPC). DLPC is enabled by default. It does not use the Min and Max sliders because the algorithm automatically detects the best range for laser power variation.

 

Data Generation

This option allows the user to fine-tune the behaviour of the Z/D/C sensor.

Intelligent processing

Turn this option on for additional processing of data. This is particularly useful for reducing spurious signals when scanning complex reflective surfaces

 

Signal Boost - light immunity

This option enhances the sensor ability to capture data in generally inappropriate conditions, such as sunny places.

This option allows the user to increase the signal level from the camera. This can be used when scanning dark and/or reflective surfaces. However, increasing the signal boost has the by product of reducing the sensor's immunity to ambient light.

 

Certified Settings checkbox:

When this option is enabled all settings in the tab are set to their default values. For the best results, it is  recommended to use 'Certified settings'.

When all changes are made, confirm with 'Apply' button.
