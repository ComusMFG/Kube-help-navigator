Labels Menu

Labels menu is divided in 5 sections as follows:

Edit labels section

Command

Description

Details

Edit mode

Switches on the Create Labels mode.

Arrange labels section

Command

Description

Details

Auto Arrange

Switches on the auto ArrangeMode for labels.

Arrange

Used for arranging labels when the auto update mode is not on.

Label settings section

Command

Description

Details

Colouring

Launches a dialog for colour settings of the labels.

Format

Launches a dialog for information settings of the labels.

Show MIN/MAX Point section

Command

Description

Details

Show MIN Point

Automatically creates a label for the point with maximum distance from the negative range.

Show MAX Point

Automatically creates a label for the point with maximum distance from the positive range.

Delete section

Command

Description

Details

Delete All

Deletes all labels from the current page.

 

Note:  Modifying label properties from the menu affects all the inspection labels (but not those created in normal mode). If you wish to modify a particular inspection label use the commands from Labels Context Menu instead.
