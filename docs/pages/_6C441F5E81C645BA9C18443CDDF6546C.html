Basic Scanning Introduction

Description: Basic Scanning Introduction is a simple outline to general aspects of the scanning process. 

Planning a scan

When setting up the ModelMaker system to perform a scanning job, first check that the localiser and sensor geometry allows access to all areas of the part. To do this, perform a quick dry run with no scanning to ensure:

  • That the sensor can scan at the nearest point of the object to the localiser base

  • That the sensor can scan at the furthest point of the object from the localiser base

  • If capturing Datum Points from the part, check that the probe has access to these points

  • If using Datum Cones, for example when scanning a whole car, it is recommended to perform a dry run to ensure the layout is correct for the size of object

Before capturing any data:

  • Ensure the localiser and sensor are Set Up Correctly

  • Ensure the system performance is within Specification

Using the localiser to operate the scan menu

 

The KUBE software Scan Menu is designed to be operated by moving the localiser up and down. If you have not previously used the localiser with KUBE, the direction of movement needs to be calibrated. To do this, select System > Localiser Menu Operation and follow the on-screen wizard.

Now the up/down movement of the localiser can be used to highlight different menu items. The menus are operated via the switches, Left 'A' button and Right 'B' button.
