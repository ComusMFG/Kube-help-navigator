Parallel Plane Check

Description: Parallel Plane Check is when two parallel planes of the alignment block are scanned. The distance between the planes is then compared to the actual distance on the block to give an indication of the accuracy of the system.

Procedure

  • Scan plane 1 horizontally in one continuous motion, keeping the sensor approximately normal to the surface.

  • Pause the scan, rotate the sensor 180 degrees and scan plane 1 again.

  • Now scan plane number 3, in the same manner.

RMS limits for FARO Gold arm

Probe RMS: depends on the arm accuracy. For FARO Gold arm is recommended the max RMS value to be less than 0.015mm.

Stripe RMS: this value depends on the used sensor. Here follows a table with recommended max values for different sensors (in case a FARO Gold arm is used in the system):
