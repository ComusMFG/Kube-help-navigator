Unlock

This command is accessible from the tree context menu > Unlock.

Description: Unlock command unlocks single or multiple entities or groups so that they will be affected when updating the current CS. It is available for all entities with the exception of transformations and view positions.

When entities are unlocked the small push-pins will disappear on their icons.

Unlocking can be performed even when there is already an active transformation. In this case there are two options:

Unlock where it is

The entities are unlocked at their current position and any other changes (back to World CS or updating with another transformation) will affect them.

Unlock and go to CCS

he entities are unlocked and applied to the Current CS.

Cancel

Cancels this dialog and leaves the entities at their current state.

Use Unlock to set objects that will be registered to a reference.
