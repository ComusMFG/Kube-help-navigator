Multi-Site Scanning Introduction

If the object to be scanned exceeds the range of the scanning system then it is necessary to use the multi site scanning system.

Scanning introduction

This feature allows the range of ModelMaker to be extended over and above the physical size of the localiser and sensor combination by setting up several scanning positions (or sites) around the zone to be measured.

A typical application of this technique is the scanning of a full size car (exterior and/or interior) but the technique can also be applied to a number of other applications such as scale models or full size clays (immovable objects).
