Metris MCA Localiser Set-Up

Handling Your Localiser

The localiser is a precision measuring instrument, please treat it with care.

The localiser has been designed to withstand a typical shop-floor environment, nevertheless, please ensure that it is handled with care according to the manufacturers instructions.

Hardware Installation

Please follow instructions in MetrisMCA manual that should be included in localiser's package.

Software Installation

All files required for the correct working of the MetrisMCA arm are delivered as part of the KUBE installation.

Localiser Set-up Process

  • Ensure the localiser is rigidly mechanically mounted.

  • Mount the handgrip to the arm

  • Mount a mechanical or electronic probe to the handgrip

  • Connect all the leads.

  • The software installation of KUBE should be completed.

  • Run KUBE software. Enter System > Hardware Settings  and go to Localiser page.

  • Select Metris MCA as localiser and Apply settings changes.

If the localiser is switched on for the first time it is not initialised. In this case the arm initialisation dialog appears first:

  • Move the arm to set home positions for all the axes.

When ready the information in Hardware settings window will be updated:

If probe changes are required, please refer to the section "Metris MCA Advanced settings".

To perform probe qualification, please refer to the section "Localiser Probe Calibration".

 

Arm and Probe Buttons Assignment

Currently there are 5 buttons on the MetrisMCA arm, that are assigned as follows:

Two buttons on the arm it-self

Red button -> assigned to the 'A' button functionality in KUBE (exit, finish, cancel)

Blue button -> assigned to the 'B' button functionality in KUBE (capture, start)

Three buttons on the handgrip

The front button -> assigned to the 'B' button functionality in KUBE (capture, start)

Two side buttons -> assigned to the 'A' button functionality in KUBE (exit, finish, cancel)

Probe buttons

The probe mounted to the handgrip could have one or two buttons on it. All these react as 'B' buttons in KUBE (capture, start).
