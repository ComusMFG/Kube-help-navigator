Subdivide

Description: Subdivides larger triangles within the selected mesh areas into smaller ones.

Parameters:

MaxEdgeType sets the method for calculating the maximum edge length. Available options are: MshAvg maximum edge length will be based on the average edge length of the whole mesh. SelAvg maximum edge length will be based on the average edge length of the selected area. Exact maximum edge length will be based on the MaxEdgeLength parameter.

MaxEdgeLength maximum edge length of the triangles in the resulting mesh. Valid when MaxEdgeType=Exact.

Decimate sets whether to remove the thin triangles, i.e. that have an angle less than the 20 degrees, or not. Available options are Yes and No.

UI Commands:

Mesh > Subdivide from the main menu. Tools > Subdivide from the tree context menu for meshes. Ctrl + U shortcut.

Examples:

Subdivide( MaxEdgeType="MshAvg", MaxEdgeLength=1.000, Decimate=Yes )
Subdivide( MaxEdgeType="SelAvg", MaxEdgeLength=0.000, Decimate=No )
Subdivide( MaxEdgeType="Exact", MaxEdgeLength=5.000, Decimate=Yes )
