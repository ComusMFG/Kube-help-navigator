Select Thin Triangles

This command is accessible from Select > Scan Data > Thin Triangles or Select > Mesh > Thin Triangles.

Description: Select Thin Triangles command selects areas of visible scans and meshes containing triangles having an angle smaller than the given value.

 

This command works on scan data and meshes only. Note that it removes any previous scan data and mesh selections. Other data types remain unaffected. Default value is 10 degrees.

Example

 

Selected triangles have angles smaller than 9 degrees

Default value is 10 degrees.

Select Thin Triangles is useful if you want more even distribution of the points on the surface.
