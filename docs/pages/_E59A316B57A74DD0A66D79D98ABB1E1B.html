Hardware Settings - Postprocessing Tab

Description:Postprocessing tab displays the settings concerning the postprocessing operations.

The tab is divided in four sections and a checkbox for 'Certified settings':

Profiles:

 

Remove reverse scans

ModelMaker data quality is often better when scan data is gathered in one direction only. This function is disabled by default.

Use this function to automatically prevent data being captured in the Reverse direction.

 

Filter by angle

Removes data where the angle between the sensor and object in the scanning direction is greater than the value 'Maximum angle'. The function is enabled by default with a value of 60 degrees.

Note: This function works best when 2D sampling is also enabled.

 

Area (2D) sampling

'Enable' checkbox

Allows area sampling to be switched on/off during scanning. If this checkbox is enabled (default option) parameters for time and distance should be adjusted:

  •  'After scan' applies 2D sampling to all patches at once when 'Scan' mode is exited.

  •  'During pause' applies 2D sampling to the patch when in 'Pause' mode. This option is enabled by default.

Note: If 'Remove reverse scans' is enabled, one single patch will be created after sampling.

  • 'From sensor' applies 2D sampling with the default distances for the current sensor. This option is enabled by default.

  • 'Custom' specifies the spacing between points in U and V directions on the plane fitted for every patch

 

Certified Settings checkbox:

When this option is enabled all settings in the tab are set to their default values. For the best results, it is  recommended to use 'Certified settings'.

When all changes are made, confirm with 'Apply' button.
