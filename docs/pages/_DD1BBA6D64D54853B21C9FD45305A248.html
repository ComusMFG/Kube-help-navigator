Lock in Space

This command is accessible from the tree context menu > Lock in Space.

Description: Lock in Space command locks single or multiple entities or groups so that they won't be affected when updating the Current CS. It is available for all entities with the exception of transformations and view positions.

In some cases it is necessary to register objects (meshes, scan data, etc.) to a CAD model. This way it must be set which entities will not be affected by the transformation, i.e. the CAD model and eventually its nominal datum entities. In order to do that, mark these entities (by left-click on their names in the Entities tree while holding Shift or Ctrl buttons.) Then right-click and select Lock in Space command. This will mark them as locked in the World CS. A small push-pin will appear on their icons:

When current CS is updated with some transformation all entities in the scene with the exception of locked ones are affected.

Example

Locking can be performed even when there is already an active transformation. In this case there are three options:

  • Lock where it is - the entities are locked at their current position and any other changes (back to World CS or updating with another transformation) will not affect them.

  • Back to WCS and lock - the entities are set back to the World CS and then locked.

  • Cancel - cancels this dialog and leaves the entities at their current state.

Use Lock in Space to set the reference (nominal) objects when register.
