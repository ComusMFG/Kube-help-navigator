Hide Selection and Hide Selected

Hide Selection is accessible from View > Hide Selection or by pressing Shift + H.

Description: Hide Selection hides all entities in the scene (or those parts of them) that are selected. This command is grayed there is no selection or all selection is hidden.

Description: Hide Selected hides marked entities and groups that are selected (or partially selected). See Tree Context Menus for details about marking tree items. This command is grayed if the entity is not selected (whole or partially) or the group does not contain selected entities. If applied to a group that contains selected as well as unselected entities, only the selected entities (or their selected parts) will be hidden. Hiding entities (or parts of them) is not stored, i.e. next time when you open the file all entities will be displayed.
