alignment

Description: Alignment is the process of registering the sensor co-ordinate system to the localiser co-ordinate system. Without an accurate alignment, the data produced by the ModelMaker system  will be out of specification. This command is accessible from System > Alignment, by pressing the 'Alignment' button on the toolbar or by pressing Ctrl + Shift + Q.

If you have done an alignment with 3DScanners v7 you can not use it for scanning with KUBE v8 and higher. If you have done an alignment with KUBE v11 you cannot use it for scanning with KUBE v12 but you can use it with KUBE v13 and higher.

Open the command and enter the correct settings into the alignment dialogue.

It is recommended to use the Certified Settings, but if any of them need to be changed, please read the descriptions of the options in the following dialogue:

This dialogue contains four sections and a check box:

Probe diameter

Probe diameter

Diameter in mm of the ball probe on the end of the localiser e.g. 6.000. 

Note: For successful alignment, the correct probe diameter must be entered. If unsure of the diameter, use a precision caliper to check the dimensions before proceeding.

Data Capture

Number of planes

Indicates how many planes will be used during alignment procedure. For Cube alignment the default value is 5.

Number of stripes

Indicates how many stripes to be captured on each plane. Increasing the number of stripes results in a better alignment, but the procedure becomes much slower. The optimal, and respectively the default, number is 9.

Number of points

Indicates how many probe points to be captured on each plane. Increasing the number of the robe points results in a better alignment, but the procedure becomes much slower. The optimal and respectively the default number is 9.

Use every

Linear sampling applied to the captured stripes. For more details see Linear Sampling Command.

Note: Using less than five planes and nine points and stripes will result in a poor alignment and the system will then not perform to specification.

Maximum allowed plane RMS sub-group

The settings in this group restrict the plane fit RMS when capturing probes and stripes. If the value exceeds the limit, a warning will sound. Reject the capture by pressing 'B' button, or continue.

Probe RMS

Depends on the localiser accuracy. The default value is 0.015mm (set for FARO Gold arm).

Stripe RMS

Value depends on which sensor type is used.

 

Sensor sub-group

Ambient threshold

Box contains the ambient threshold setting of the current material item option. Sets the sensitivity of the sensor to surrounding light. Default value is 96.

Laser power

Sets the laser power during alignment procedure. Default value is 1 for white alignment block and for MMW, MMX/Y and MMZ sensors. Default value is 4 for white alignment block and for MMD/C sensors.

Restrict roll angle

Check box is to determine the angle between the sensor and the plane normal. With this box checked, the sensor needs to be kept between 15 and 60 degrees to the surface. Enabled by default.

 

Button Operation

Use the radio buttons to choose the functions of the 'A' and 'B' buttons.

Note: For the KScan systems the functionality of 'A' and 'B' buttons is pre-defined and the buttons can not have any different assignment. For these systems the first option is disabled.

 

Capturing Order

First plane, first stripe->Last plane, last stripe

This is the default order for capture, i.e. for each selected plane from the alignment block capture with the probe and then capture the stripes. For example, if 5 planes should be used and 9 points and 9 stripes should be captured for each plane, then the procedure is as follows:

plane 1: capture 9 points
plane 1: capture 9 stripes

plane 2: capture 9 points
plane 2: capture 9 stripes

plane 3: capture 9 points
plane 3: capture 9 stripes

plane 4: capture 9 points
plane 4: capture 9 stripes

plane 5: capture 9 points
plane 5: capture 9 stripes

Use this option with FARO and CimCore localisers.

First plane, last plane->First stripe, last stripe

All selected planes from the alignment block are captured with the probe first and then the stripes are captured. For example, if 5 planes should be used and 9 points and 9 stripes should be captured for each plane, then the procedure is as follows:

plane 1: capture 9 points
plane 2: capture 9 points
plane 3: capture 9 points
plane 4: capture 9 points
plane 5: capture 9 points

plane 1: capture 9 stripes
plane 2: capture 9 stripes
plane 3: capture 9 stripes
plane 4: capture 9 stripes
plane 5: capture 9 stripes

Use this option with K-Scan localisers because the points are taken with the Space Probe and the stripes are taken with the sensor attached to the K-Scan probe.

 

Certified Distances

Known plane to plane distance

Choose the appropriate button, depending on the number of used planes and respectively the known distance between them. Default value is 2.

For certified system performance the certified distances must be used. Enter the distances marked on your alignment block into the relevant dialogue boxes.

Note: For successful alignment, these values must be correct. Please take care when entering the values 

Certified settings

Should be used. Set by default.

When the correct settings are filled in the alignment window, follow the wizard as explained in the System Setup Section.
