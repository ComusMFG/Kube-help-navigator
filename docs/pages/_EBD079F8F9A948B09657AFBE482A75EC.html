Local Administrative Privileges

If you get the You must have local administrative privileges to use this software message when start KUBE, you have to enable every user to run the software. In order to do that, perform the following steps:

Log in as Administrator or other user with administrative privileges:

Windows 2000:

Run regedt32.exe. Select window named HKEY_LOCAL_MACHINE on Local Machine and find the SOFTWARE\3DSCANNERS\KUBE_xx.x key, where xx.x is the KUBE version. Select this key and call Permissions form the Security menu.

Windows XP:

Run regedit.exe and find the HKEY_LOCAL_MACHINE\SOFTWARE\3DSCANNERS\KUBE_xx.x key, where xx.x is the KUBE version. Right click on this key and select Permissions from the context menu.

 

Common for both Windows 2000 and Windows XP:

On the dialog that will appear find the Everyone user. If there is not such user, press Add button and in the next dialog that will appear type-in Everyone. Press OK to add this user. Now set Allow to Full Control for the Everyone user. Press Apply button and close the dialog.

 

Now every user of the system will be able to run KUBE xx.x.
