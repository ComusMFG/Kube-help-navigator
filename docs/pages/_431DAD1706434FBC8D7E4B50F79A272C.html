Profiles in HW settings

'Name' listbox

Shows the profile currently being used. Select a profile name from the drop-down list to apply a new alignment profile, import, view, save, or delete profile.

'Import' button

Imports profiles created in earlier versions of KUBE. The chosen .mmp file will be listed in the profile listbox the next time KUBE is started.

'View' button

Displays the settings of the current profile.

Example

'Save as' button

Saves the current settings in a new profile.

'Delete' button

Removes current profile.
