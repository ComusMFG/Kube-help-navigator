Reverse

This command is available for Datum Line, Datum Cylinder, Datum Plane, and Datum Circle entities.

Reverse command for a Datum Line or Cylinder

This command is accessible from the tree context menu for Datum Line / Datum Cylinder > Reverse.

Description: Reverse command reverses the direction of a datum line or the cylinder axe. First point becomes end point and vice versa. Signs of the co-ordinates of the line tangent are reversed. The position and orientation of the line remain unchanged.

Reverse command for a Datum Plane or Datum Circle

This command is accessible from the tree context menu for Datum Plane / Datum Circle > Reverse.

Description: Reverse command reverses direction of the normal of a datum plane or datum circle. The signs of normal co-ordinates are simply inverted.

For example, if the vector of a normal has the following co-ordinates [+0.5, +0.3, -0.4], after applying the command, the co-ordinates will be [-0.5, -0.3, +0.4]. The position and orientation of the plane remain unchanged.
