Alignment Check

Procedure

  • Ensure the localiser hardware and software set-up is complete

  • Mount the alignment block so that all planes can be reached comfortably.

  • The block should be mounted in the position shown in the diagram. The distance between localiser and block will depend on the localiser type. For an 8' FARO arm it is approximately 500mm (50mm).

  • Run KUBE

  • Open a new document

  • Go to the toolbar and from the 'Surface materials' listbox select 'Certified settings' profile. This will change the scanning parameters to the certification settings.

The results of the certification tests are not valid unless the certification settings are used. 

 

Different certification methods:

  • Certification Flat Plane

  • Certification Parallel Planes

  • Certification Corner

 

What to do if the results exceed the values specified on your System:

  • Check the certification settings are in use.

  • Ensure the system hardware is setup as described in Alignment Preparation.

  • Repeat the alignment procedure.

  • Repeat the flat plane check.

If the results are still out of specification, contact your distributor.
