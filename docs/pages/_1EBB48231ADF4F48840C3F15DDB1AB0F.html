Capture Round Slot

Description: Capture Round Slot allows a datum round slot to be captured using the localiser probe or to be extracted by scanning using the sensor. In case of tactile measurement a plane is necessary where the round slot will lie. This command is accessible from the Localiser Menu Datum > Round Slot.

Wizard

When you select Datum > Round Slot from the localiser menu the wizard behaves depending on the settings in System > Preferences > Datums > Capture Method (Datum Capture Method) dialog. If Round Slot listbox is set to Prompt the following dialogue will appear:

At this stage there are offered 2 possibilities for measuring the round slot:

  • If you selectTactile, you will capture the slot using the localiser probe. See Capture Round Slot Wizard.

  • If you select Scanning, you will scan the slot using the sensor. See Scan Round Slot Wizard.

 

Capture Round Slot Wizard

When Tactile is selected you will need a plane where the round slot will lay on. KUBE offers two options:

  • to capture a plane.

  • to use an existing plane or plane reducible entity. If there are existing planes, circles, cylinders, cones, or slots the following dialogue will appear when Datum > Round Slot  is selected from the localiser menu:

If the Capture 3 or more points to define a plane option is selected, the Capture Plane procedure will start. If one of the existing planes from the list is selected, it will be used for the base of the slot. If there are no existing planes, this dialogue is omitted and the procedure will start immediately to capture a plane.

Note 1: If Always capture method is used then no dialog for selecting existing plane reducible entities appears but Capture Plane procedure will automatically start. See System > Preferences > Datums > Capture Method (Base Plane Definition) for details.

Note 2: KUBE projects the centre of the slot onto the captured (or selected) plane. So even if you use another plane for capturing the slot points, finally the round will lie on the captured (or selected) plane.

 

Capture Round Slot

  • When the base plane is captured or selected, capture the points that define the first semicircle of the slot:

  • Press 'B' button consecutively to collect the necessary points. Hold 'B' button to delete the last captured point if necessary. Finally press 'A' button to finish this semicircle. Captured points are projected onto the plane and a circle is fitted. Now capture the points that define the second semicircle of the slot.

  • Press 'B' button consecutively to collect the necessary points. Hold 'B' button to delete the last captured point if necessary. Finally press 'A' button to finish. Captured points are projected onto the plane and a circle is fitted.

The round slot is defined. Its radius is the average of the radii of the two circles plus the probe radius. Its length is the distance between the centres of the two circles plus 2 x slot's radius. Slot's normal is parallel to the plane normal and slot's axis is parallel to centres of the circles.

A round slot cannot be created if there are less than three captured points for each semicircle. In this case a warning message will appear.

KUBE will fit a round slot from the set of the captured points. The slot is automatically compensated with the localiser probe. The information about centre, width (2*radius) and height (height means the full length of the slot, i.e. the distance between the centres of the two semicircles + 2*radius) of the resulting slot, and the RMS of fitting will be displayed:

Example

  • Press 'A' button to reject the resulting round slot or 'B' button to create it.

After finishing the capture procedure, KUBE will issue a dialog, asking you if you will continue capturing round slots.

Example

  • Press 'A' button to exit the capture mode or 'B' button to continue capturing.

 

Scan Round Slot Wizard

When Scanning is selected, an additional window (which displays the scanned data) will pop-up and the following dialogue will appear:

  • Press 'B' button to start scanning. Scanning is performed as in the normal Scan mode, i.e. after you press 'B' button KUBE starts capturing a patch and after you press it again KUBE will stop scanning and will enter in Pause mode.

Example

  • When done with the scanning press 'A' button to exit.

If the extraction is successful you will get:

  • the centre of the slot.

  • the width (2*radius) and the height (height means the full length of the slot, i.e. the distance between the centres of the two semicircles + 2*radius) of the slot.

  • the RMS of the extraction.

Note: Round slot detection is controlled by Tolerance and Depth parameters. See System > Preferences > Datums > Detection Tolerances for details.

Example

  • Press 'A' button to reject the resulting round slot or 'B' button to create it.

After finishing the scan procedure, KUBE will issue a dialog, asking you if you will continue scanning round slots.

Example

  • Press 'A' button to exit the capture mode or 'B' button to continue capturing using Scanning method.
