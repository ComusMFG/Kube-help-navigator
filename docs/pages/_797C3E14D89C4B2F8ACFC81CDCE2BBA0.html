FARO USB Localiser Set-up

Handling Your Localiser

The localiser is a precision measuring instrument, please treat it with care.

The localiser has been designed to withstand a typical shop-floor environment, nevertheless, please ensure that it is handled with care according to the manufacturers instructions.

Hardware Installation

Please follow instructions in FARO manual that should be included in localiser's package.

Software Installation

FARO USB Driver should be installed in addition to KUBE installation package in order to use FARO Platinum/Titanium localisers with KUBE software. Several releases of FARO USB Drivers have been made by the time of the release of KUBE software.

KUBE software has been tested with following versions of FARO USB Driver:

  • FARO ATL 5.4.0.2 if 155 BIOS is applied to localiser.

 

Localiser Set-up Process

  • Ensure the localiser is rigidly mechanically mounted (as per FARO manual).

  • When using the FARO arm with KUBE, a 6mm ball probe is recommended.

  • Connect all the leads:

Connect the power cable to the FARO localiser.

Connect USB cable to the localiser.

Connect USB cable to the PC.

Connect trigger cable to the localiser.

Connect trigger cable to the MMIB.

  • Software installations of KUBE and approved version of FARO USB Driver should be completed.

  • Run KUBE software. Enter System > Hardware Settings  and go to Localiser page.

Select FARO Platinum or FARO Titanium depending on your localiser type and Apply settings.

  • If there is a problem with FARO USB Driver installation or it has not been completed then appropriate warning message box will be displayed.

  • If unsupported version of FARO USB Driver is installed on the PC appropriate message box will be displayed. Consider upgrade that software with the version mentioned in Software installation section.

  • Press Advanced settings...  button to enter FARO Platinum/Titanium specific settings page.

  • Press Diagnostics...  button and check on the displayed informational box if localiser specific information such as position, joints, buttons and temperature is displayed and updating.

  • Calibrate the select probe if necessary. Please check Localiser probe calibration section
