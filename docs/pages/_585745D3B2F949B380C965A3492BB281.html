Delete All Labels

The Delete All Labels command is accessible from Measure > Delete All Labels or from the context menu for labels > Delete All Labels.

Description: This command deletes all labels in the scene no matter if their entities are visible or hidden.

To delete individual label right-click on it and from the context menu select Delete Label command. To delete labels from the Entities tree, mark the desired datum entities, right-click and from the context menu select Remove Label command.
