Inspection

Description: The second step analyses the surface, locates corrosion areas and calculates their characteristics.

Inspection Description and procedure:

Skip

If this option is enabled the processing goes straight to the next step, i.e. Print.

The parameters are explained below by the order of their using in the inspection algorithm.

Input File

Specifies the file from where the input data is loaded. If the previous step has not been skipped there is a file name provided by default.

Nominal Wall Thickness

Used for calculating the Corrosion Threshold if the latter is specified as percentage of the wall thickness. Default value is 10mm.

Corrosion Threshold section

In this section the threshold value can be set by two different ways. This parameter is obligatory for the correct corrosion detection.

Absolute Value areas deeper than this value are assumed corrosion areas. Default value is 1mm.

% of Wall Thickness areas deeper than the given percentage of the wall thickness are assumed corrosion areas. By default it is set to 10% of the wall thickness.

Schematic

Analysis Area Size

Specifies the size of the square neighborhood area around each point, which is analysed to determine whether the point should be treated as normal or uneven surface. The result is used as initial guess by a further step performing more precise analysis, non-relying on the Analysis Area Size parameter. Overall this parameter affects mainly the speed of the process but not the quality, unless its value is too extreme. A default value is automatically calculated for each data set and using it is highly recommended. For faster inspection it is recommended to use values between 5mm and 10mm. But if the algorithm failed you may increase this value, which leads to slower but more precise processing.

Average Welding Width

This parameter is used to qualify data as welding or not (see explanation below). Default value is 8mm.

Min Welding Length

This parameter is used to qualify data as welding or not (see explanation below). Default value is 100mm.

The next stage of the process is analysing the uneven surfaces in order to classify them as weldings or potential corrosion. In order to qualify as a welding an uneven area must have length greater than Min Welding Length and width comparable to the Average Welding Width. Areas which were suspected weldings but did not qualify as such are treated as normal surface areas.

The weldings found are used to separate the whole surface into sub-surfaces, the potential corrosion points are removed from the data and then the whole surface is reconstructed in order to create the so called reference (reconstructed) surface, which represents a guess of what the surface looked like before the corrosion took place.

Each point of the input data is compared to its corresponding reconstructed point and if the difference is greater than the Corrosion Threshold AND the point belongs to the data that was originally selected (see First step Merging) it is marked as corrosion.

The corrosion points are then segmented into corrosion areas by applying the selected Rules of Interaction.

Rules of Interaction

Selects the rules that determine the segmentation of the corrosion areas. Currently available rules are.

  1. ASME RSTRENG.

  2. Custom GU version 10.01.2005.

  3. Custom GdF.

Gas Flow from to

These values are not used in the calculations but are only saved in the output file so that they can be passed on to the next step. They designate the direction of the gas flow that is printed on the report pages containing different representations of the full unfolded surface.

Output File Resulting file is output into a .pir file which contains all the parameters and results of the inspection calculations. The default file name is the same as the original file. This file is the input to the next step (if enabled).

Dialog parameters are automatically saved in a log file having the same name as the original file with _inspect suffix and .log as extension. This is a text file and its contents could be as follows:
