Unify Normals Interactive

This command is accessible from Mesh > Normals > Unify Interactive.

Description: Unify Normals Interactive command detects a submesh and inverts the normals when clicking on a triangle with reverse normal (relative to view position.) Triangles are flat and have two faces, front and back. Sometimes it is impossible to determine the correct facing of a triangle: front or back and the result is distortion in the object view. An object may contain triangles, which are correctly orientated and other triangles, which are not. You can view the direction of normals using Display Normals from the View menu.

Unify Normals Interactive command is grayed if there is no selection or all selections are hidden. It works on wholly selected entities as well as on partial selections. For efficient use it is recommended to use this command on a wholly selected mesh.

When call Unify Normals Interactive KUBE will enter in pick mode. The mouse pointer will become a cross. While in this mode you can rotate the viewport using Shift + left mouse button, pan using Shift + right mouse button, and zoom using Shift + middle mouse button or the mouse wheel.

Mouse pointer in Unify Interactive mode

Exit this mode by switching to another one Zoom Window, Zoom Mode, Rotate, or Pan. This mode is not stored so when you open another window, Zoom Window mode will be enabled.

Use Unify Normals Interactive to unify the normals of a STL mesh generated from a CAD model and imported into KUBE.
