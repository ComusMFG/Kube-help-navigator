Remove Faulty Areas

This command is accessible from Mesh > Remove > Faulty Areas.

Description: Remove Faulty Areas command removes visible selected triangles, which distort the image. This means that all triangles, which planes form 3D angle less than the given degree, will be removed. This command is grayed if there is no selection or all selections are hidden. It works on wholly selected entities as well as on partial selections.

Remove triangles forming 3D angle of less than

Maximum 3D angle between triangles that must be removed. Default value for this command is 60 degrees.
