Offset Points

This command is accessible from Edit > Offset Points.

Description: Offset Points command is applied to scan data and meshes only. It has different behaviour depending on the data type. The command is grayed if there are no visible selections of scan data or meshes. Offset Points can be applied to whole entity as well as partial selection.

In case of scan data it offsets all visible and selected scans along the normal toward the sensor. These entities will only be moved in the space, i.e. their geometry will not be changed.

In case of meshes it offsets every point in all visible and selected meshes along its normal. This will cause the entities to inflate.

Offset

Distance along the normal. Default offset is 0.05mm.
