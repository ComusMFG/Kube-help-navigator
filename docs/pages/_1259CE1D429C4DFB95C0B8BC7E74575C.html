Open

This command is accessible from the File > Open, by pressing Ctrl + O, or by pressing Open button on the toolbar.

Description: Open is a standard Windows command to open an existing file. In KUBE this could be:

  • ModelMaker file with .sab2 extension (documents generated by ModelMaker version 6 and above)

  • ModelMaker file with .sab extension (documents generated by ModelMaker versions 4 and 5)

  • ModelMaker file with .cta and .msh extensions (documents generated by ModelMaker version 3)

  • external files of different formats. The following is a list of currently supported file formats:

Note: [1] - These imports are available only when the corresponding Dongle option is enabled.

When importing CAD models from the formats designated with [1] the following dialog appears:

Tolerance

Specifies the maximum allowable distance between the original surface or solid and the midpoints of the polygon edges from the triangulated surface. Default value is 0.01mm.

Neighbour distance

Specifies the maximum allowable distance between points from different sub-meshes that will be assumed as single surface and unified together. Default value is 0.3mm.

Importing other file formats is useful in the case when scan data will be compared to a CAD model.
