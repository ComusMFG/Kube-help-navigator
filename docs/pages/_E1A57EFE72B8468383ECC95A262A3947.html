Import XY Grid (Scan Data)

This command is accessible from Scan Data > Create XY Grid > Import.

Description: Import XY Grid command imports point cloud from *.txt, *asc, or *.csv file formats. The points should be described by their X, Y, and Z co-ordinates, separated by any character excluding digits, plus sign, minus sign, and dot. Every point should be on separate row. This command is unavailable if there is no scan data/mesh selection or all selections are hidden.

Existing  XY grids can be exported using File > Export command to 'ASCII Points (*.asc)' file format and Export option set to Points.
