Invert Normals

This command is accessible from Scan Data> Invert Normals .

Description: Invert Normals command flips the normals of a scan entity. This means that if an object is convex, after the operation it will be concave, and vice versa. This command is grayed if there is no selection or all selections are hidden. It works on wholly entities, no matter if entirely or partially selected.
