Merging

Description: The merging calculates a cylinder fit for the raw data, unfolds it around that fit, aligns the scan patches for better overlapping and creates a regular grid mesh. In order to carry out the processing correctly the following must be complied with:

    • There is one and only one datum point in the entities pane (called briefly Reference Point - RP) which should be created so that it is located at the end of the scan from where the gas comes.

    • There is a selection of the scan data specifying areas of potential corrosion.

Merge Description and procedure:

Depending on the parameters the following steps are performed on the loaded scan data:

Skip

If this option is enabled the processing goes straight to the next step, i.e. Inspect. If it is disabled then the cylinder fit will be calculated for all non-hidden scan data (for complex surfaces make sure you hide all significant areas of data which do not belong to the targeted cylinder).

Filter out data more than ... deg from cylinder

If this option is enabled then all points with a normal more than the specified degree from the cylinder normal are removed from the next cylinder fit calculation. Default value is 10deg.

Schematic

Filter out data farther than ... mm from cylinder

If this option is enabled then all points further away than specified distance are removed from the next cylinder fit calculation. Default value is 1mm.

If any filtration is done cylinder fit is re-calculated. The rest of the parameters are explained below by the order of their using in the merge algorithm.

The next step is transformation of the coordinate system so that the global system Y axis goes through the 12 oclock point or other clock position and the X axis coincides with the cylinder fit axis while pointing in the direction from the RP towards the other end of the scan data.

Y=0.0 at oclock

Sets clock position that defines the Y axis. Default value is 12 oclock.

Reference point at oclock

Sets clock position for the reference point (RP). By default it is at 12 o'clock. Using this parameter and the coordinates of the RP the coordinates of RP are calculated by rotating the RP around the cylinder fit axis.

Reference point at ... mm along X

Sets position of the RP on the X axis. By default it is at 0mm. This value is used for transformation of the (0,0,0) along the X-axis so that the new coordinates of the RP are the same as specified in this edit box.

The next step is unfolding the data around the global X axis (cylinder fit axis). The resulting coordinate system is offset in Y-direction so that Y = 0.0 where the specified in the dialog clock position is.

Then it follows a minimisation of the distance between overlapping areas of scan patches and merging into a regular grid mesh.

X resolution

Specifies the grid resolution for the generated mesh along X axis. By default this value is set to 0.5mm.

Y resolution

Specifies the grid resolution for the generated mesh along Y axis. By default this value is set to 0.5mm.

Area of interest from to oclock

Specifies the area covered by the grid. All other data is cropped. By default these two values are set to 12 o'clock, which means the whole selected surface is used. The resulting area for inspection is actually the section between the selected area and the defined area of interest.

Example

Void data if discrepancy > mm

If this option is enabled the data is voided if overlapping scan patches differs more than this value. By default it is 0.5mm. For better analysis it is recommended to use 0.2mm.

Fill holes smaller than mm

If this option is enabled all holes in the range image grid smaller than this value are filled. By default it is 10mm.

Output File

Resulting file is output into a .pii file with the name specified. The default file name is the same as the original file. This file is the input to the next step (if enabled).

Output Intermediate Files

If this option is enabled the following files are generated: FileName_PreAligned.sab2, FileName_Aligned.sab2, and FileName_Merged.sab2, where FileName is the name of the original file.

Dialog parameters and cylinder fit results are automatically saved in a log file having the same name as the original file and .log as extension. This is a text file and its contents could be as follows:

Intermediate Files:

FileName_PreAligned.sab2 scan patches are merged into individual meshes. Each mesh entity is named Patch as Mesh #N, where N is the number of the patch.

FileName_Aligned.sab2 merged scan patches are aligned so that the best overlapping is achieved. The aligned patches are named Patch as Mesh Aligned #N, where N is the number of the aligned patch.
