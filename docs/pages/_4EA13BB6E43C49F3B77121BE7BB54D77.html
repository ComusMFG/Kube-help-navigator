Preferences - Arm Menu Appearance - Datum

Arm Menu Appearance - Datum settings let you customise the Datum localiser driven menu of KUBE. Buttons can be added or removed so that the menu can appear in the way that user prefers.

Localiser driven menu Group

Available buttons

List of available buttons for this menu, i.e. the buttons that will not be displayed. Currently only the StandBy button is not shown by default.

Current buttons

List of buttons that will appear in this menu.

Right arrow button

Select a button from Available buttons list and press this button to move it to Current buttons list. This adds a button to the new configuration of the menu. The button is disabled if there are no buttons in Available buttons list.

Left arrow button

Select a button from Current buttons list and press this button to move it to Available buttons list. This removes a button to the new configuration of the menu. The button is disabled if there are no buttons in Current buttons list.

Up arrow button

Select a button from Current buttons list and press this button to move it one position up. This rearranges buttons from the new configuration of the menu. The button is disabled if there are less than two buttons in Current buttons list.

Down arrow button

Select a button from Current buttons list and press this button to move it one position down. This rearranges buttons from the new configuration of the menu. The button is disabled if there are less than two buttons in Current buttons list.

Note: Double-click on a button from Available buttons list to move it to Current buttons list. Double-click on a button from Current buttons list to move it to Available buttons list

Default button

Press this button to set the default appearance of the localiser driven menu. It will move all buttons from Available buttons list to the Current buttons list and will arrange them in the default order.
