Capture Cylinder

Description: Capture Cylinder allows a datum cylinder to be captured using the localiser probe or to be extracted by scanning using the sensor. It can be used to measure cylindrical objects such as pipes, holes, etc. When measuring holes, the advantage is that besides measuring the radius it also gives the direction of the hole. This command is accessible from the Localiser Menu Datum > Cylinder.

Wizard

When you select Datum > Cylinder from the localiser menu the wizard behaves depending on the settings in System > Preferences > Datums > Capture Method (Datum Capture Method) dialog. If Cylinder listbox is set to Prompt the following dialogue will appear:

At this stage there are offered 2 possibilities for measuring the cylinder:

  • If you selectTactile, you will capture the cylinder using the localiser probe. See Capture Cylinder Wizard.

  • If you select Scanning, you will scan the cylinder using the sensor. See Scan Cylinder Wizard.

 

Capture Cylinder Wizard

When Tactile is selected, the following dialogue will appear:

  • Press 'B' button consecutively to collect the necessary points. Hold 'B' button to delete the last captured point if necessary. Press 'A' button to finish.

If Tolerance check is enabled and the next point is out-of-tolerance KUBE will play warning sound and will display out-of-tolerance value in yellow. See System > Preferences > Datums > Form Tolerances for details.

Note: In order to capture a cylinder correctly get at least four points from each of the four opposite sides on the cylinder's in-between wall. Or take at least six points on both cylinder bases.

Sometimes a cylinder cannot be created due to lack of points or irregular distribution of the captured points. In this case a warning message will appear.

  • Select the side of the cylinder ('A' - inner side or 'B' - outer side)  from which the points were captured.

If the ball probe is used, it will inflate or deflate the cylinder with the radius of the probe depending on which side was captured. This is very important for the correct cylinder diameter because every localiser returns co-ordinates of the centre of its probe. See Offset On Curved Surfaces for details.

KUBE will fit a cylinder from the set of the captured points. The information about the radius (diameter) of the resulting cylinder and the RMS of the fitting will be displayed:

Example

  • Press 'A' button to reject the resulting cylinder or 'B' button to create it.

After finishing the capture procedure, KUBE will issue a dialog, asking you if you will continue capturing cylinders.

Example

  • Press 'A' button to exit the capture mode or 'B' button to continue capturing using Tactile method.

 

Scan Cylinder Wizard

When Scanning is selected, an additional window (which displays the scanned data) will pop-up and the following dialogue will appear:

  • Press 'B' button to start scanning. Scanning is performed as in the normal Scan mode, i.e. after you press 'B' button KUBE starts capturing a patch and after you press it again KUBE will stop scanning and will enter in Pause mode.

Example

  • When done with the scanning press 'A' button to exit. If the extraction is successful you will get information about the radius (diameter) of the resulting cylinder and the RMS of the extraction.

Note: Cylinder detection is controlled by Tolerance parameter. See System > Preferences > Datums > Detection Tolerances for details.

Example

  • Press 'A' button to reject the resulting cylinder or 'B' button to create it.

After finishing the scan procedure, KUBE will issue a dialog, asking you if you will continue scanning cylinders.

Example

  • Press 'A' button to exit the capture mode or 'B' button to continue capturing using Scanning method.
