Select Reverse Scans

This command is accessible from Select > Scan Data > Reverse Scans.

Description: Sometimes the data quality is slightly affected by the direction in which the sensor is held while capturing data. Call Select Reverse Scans to select parts of a visible scan captured while scanning in reverse direction.

This command works on scan data only. Note that it removes any previous scan data selections. Other data types remain unaffected.

For maximum accuracy, it is recommend to scan in the 'Forward' direction relative to the sensor head. The forward direction is the same direction as moving 'down' in the scan menu, i.e. with the localiser probe ahead of the sensor.

Use this command to select reverse scans and then delete them if necessary.
