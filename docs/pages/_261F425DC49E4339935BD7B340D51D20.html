System Contents

A ModelMaker C system consists of some of the components listed below. Please keep in mind that actual contents depends on your purchase option.

  • ModelMaker C40 Sensor

  • ModelMaker C80 Sensor

  • ModelMaker C160 Sensor

  • Ethernet cable

  • Floor Mount Datum Cones

  • Miniature Datum Cones

  • Magnetic Datum Cones (NOT INCLUDED AS STANDARD)

  • Alignment Block

  • Alignment Block Extension

  • Probe Calibration Cone

  • 6mm Ball Probe Cal Piece

  • CimCore Probe Mount

  • FARO USB  Arm Sensor Mount

  • FARO USB Arm Mount Kit (this is comprised of Location Ring, Threaded Sleeve)

  • FARO USB Spanner

  • ModelMaker C Sensor Cable

  • ModelMaker C Power Supply Unit

  • ModelMaker C Mini Toolcase
