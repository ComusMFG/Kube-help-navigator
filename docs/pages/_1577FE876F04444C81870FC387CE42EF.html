PC Diagnostics

This command is accessible from System > PC Diagnostics.

Description: The PC Diagnostics command is destined to check the specification of your PC against the requirements of KUBE.

Call the function and a similar dialog will appear:

It will contain information about your operating system, processor, memory and display properties. On the left of each information window appear different status images:

  • The green sign means the checked parameter is OK for running KUBE. In this case the information window will be empty.

  • The yellow exclamation mark has the signification of warning message. The meaning is: this checked parameter doesn't correspond to the KUBE requirements, but it is acceptable anyway. In this case the information window will display the minimum requirements concerning the parameter and a list of possible problems when running the KUBE software.

  • The red 'x' sign indicates impossible work in KUBE. In this case the information window will show the minimum required values for this parameter to be accepted by KUBE.

The information shown in PC Diagnostics window can be stored as a text file (click on the Save button) and sent to your local Partner to assist in fault-finding.
