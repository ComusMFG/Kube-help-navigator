Instant Editing

This command is accessible from Mesh > Instant Editing.

Description: Instant Editing command applies different processing tools on meshes to areas defined in the dialog. You can apply a function using the mouse in a brush-like style or by automatically detecting and selecting all holes in the visible meshes. It is not necessary for the meshes to be selected. Using the command on other types of entities has no effect on them. If called from a tree context menu, the command works on every visible mesh, no matter if it was selected from the group or entity context menu.

Function group:

  • Type select from the drop-down list the function to be applied. Parameters in this group depend on the selected function. Available functions are:

Function

Details

Mouse cursor

Parameter

Reduce Noise (Average Noise Reduction)

Strength specifies how strong the filter to be applied, i.e. number of iterations. It ranges from 1 to 10. Default value is 1.

Fill

Method select one of the available methods: Curvature based or Flat filling.

Fill only small holes up to ... edges holes with this number of edges or lesser will be filled. Default value is 50.

Hole Processing group:

  • Select button press this button to select border triangles of the current hole in mesh.

  • Number hole in the mesh if the current hole should not have to be selected/processed, type-in the next number to jump to the next hole.

  • with up to ... edges limit for edges in holes. If a hole contains more edges that this value it will not be selected. Default value is 1000 edges.

  • Previous button press this button to select the previous hole.

  • Next button press this button to select the next hole.

It is possible to zoom, rotate, and pan the viewport as well as to change the selection while you are in Instant Editing. After every such operation KUBE will revert to the current editing mode.

Use: Instant Editing command is suitable for fixing small problems on the mesh.
