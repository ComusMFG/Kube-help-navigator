Get321Settings

Description: Runs the wizard for new 321 transformation and initialises temporary parameters for the target entities.

Dialog:

Parameters:

CoordFrame choose from the drop-down box the target co-ordinate frame.

Axis - choose from the drop-down box the target axis

XOrigin - type X co-ordinate value

YOrigin - type Y co-ordinate value

ZOrigin - type Z co-ordinate value

Direct input of the parameter values is not allowed. The command is started with temporary parameters, that are initialised through this dialog.

Example

Get321Settings( CoordFrame=&frame, Axis=&axis, XOrigin=&x, YOrigin=&y, ZOrigin=&z)
