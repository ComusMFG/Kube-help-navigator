Delete Selected

This command is accessible from the tree context menu > Delete Selected.

Description: Delete Selected command deletes marked entities/groups that are selected wholly or partially. See Tree Context Menus for details about marking. This command is available only when you call the context menu for more than one marked entities/groups with the exception of polylines it appears in the context menu of every single polyline entity or polyline group.

If an entity is partially selected, calling this command will cause the whole entity to be deleted. If applied to a group, all its entities that are wholly of partially selected, will be deleted. It is not possible to delete hidden entities/groups if the marked set contains hidden entities/groups (with the exception of polylines) the command will be grayed.

Note: There is no undo for Delete Selected.

  • When you call Delete Selected from the context menu of multiple marked entities/groups, a warning message will appear to confirm the delete operation.

  • When you call Delete Selected from the context menu of single entity/group, a warning message will appear to confirm the delete operation.

Use Delete Selected command to permanently remove from the document whole entities and groups that are selected.
