Display Sensor

Description: Display Sensor hides/shows the sensor view window, which is located in Scan Pane below the localiser driven menu and localiser position window. This command is accessible from View > Display Sensor.

  • When the 'Laser' button is on, this window displays the laser stripe in the colour red. Updating speed depends on the settings in System > Hardware dialogue. This window is hidden by default. When sensor view window is displayed, this command is marked with a tick. When Workspace is hidden this command is unavailable.

Note: The LP denotes the current laser power level.
