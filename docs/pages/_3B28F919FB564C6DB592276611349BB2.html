Fit Parallel Planes (Manual)

This command is accessible from System > Performance Check Utilities > Measure > Parallel Planes (Manual) or by pressingCtrl + P.

Description: Fit Parallel Planes (Manual) command fits a plane to the visible selection and a second plane to all the visible unselected data. The distance between the two planes is calculated. This command is grayed if there is no selection or all selections are hidden.

Example

Selection to fit parallel planes

 

The scene must contain visible selected and unselected data. No entity will be created in the document.

After the two planes are fitted the following dialog will appear:

Non selected plane / Selected plane

  • Normal - co-ordinates of the non selected / selected plane normal.

  • Offset - the smallest distance of the non selected / selected plane from the origin.

  • RMS - Root Mean Square of the non selected / selected plane fit.

Object Metrics

  • Expected plane to plane distance - enter the known plane-to-plane distance.

Result

  • Plane deviation from the centre - error between the certified distance between the planes and the measured distance between the planes. It is shown as the error for one plane only, i.e. divided by 2.

Apply button -

Press it to see the calculated error.

Note: Any points not on the two planes must be hidden or deleted before calling this command.

If you do not have an unselected data or it is hidden, KUBE will issue the error message "Not enough points selected to fit a plane"
