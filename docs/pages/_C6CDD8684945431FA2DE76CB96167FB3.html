Zoom Mode

This command is accessible from the viewport context menu > Zoom Mode, by pressing Shift + Z, or by pressing Zoom mode button on the toolbar.

Description: When this mode is enabled, hold down the left mouse button and move the mouse up or down to zoom in or out. The significant destination for the mouse move can be swapped in Preferences / Display / Rotate/Pan/Zoom dialog. Select Zoom in on mouse move up option to zoom in when you move the mouse up and vice versa. Select Zoom in on mouse move down option to zoom in when you move the mouse down and vice versa.

Mouse pointer in Zoom Mode

Exit Zoom Mode by switching to another one Zoom Window, Rotate, or Pan. This mode is not stored so when you open another window, Zoom Window mode will be enabled.

Note: Using Shift + Middle mouse button or only the mouse wheel it will always switch to Zoom mode.
