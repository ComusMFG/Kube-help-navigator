Select Triangles Based on Order

This command is accessible from Select > Scan Data > Based On Order.

Description: Select Triangles Based on Order command selects part of a visible scan based on the order in which the points were captured.

Entities list

Select on of the visible scan data entities from this list to which you will apply the selection.

Arrow buttons and sliders

The data between the upper and lower slider will be selected. The sliders may be using the forward and reverse buttons. Use the single arrow buttons to select stripes and the double arrow buttons to select patches. Text boxes left to the arrow buttons shows current range of stripes.

Lock selection sliders

Fixes the separation between the sliders.

Close button

Exits the mode without making new selection.

Refresh button

Redraws the view according to the current slider positions. Preview selection is drawn in pink.

Select inside button

Selects stripes between the sliders.

Select outside button

Selects stripes outside the sliders.

This selection tool is a mode, which means that it will stay on the left pane until you close it. During this time you can rotate, pan, and zoom the viewport in order to achieve better observation of the objects. Using arrow buttons and sliders in the dialog you can set the range of the selection that you want to make. You can check at any time whether the selection satisfies you simply by pressing Refresh button. When you are ready, press Close, Select inside, or Select outside button to exit Slider Selection of Stripes dialog with or without new selection.

This command works on scan data only. Note that it removes any previous scan data selections. Other data types remain unaffected.

Example

Select Triangles Based on Order is used to select a series of scan lines and patches even where they overlap other scans done earlier or later. This enables you to remove low quality data caused by poor scanning technique without needing to rescan the area.
