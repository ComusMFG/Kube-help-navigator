Transformation Description

The transformations are used to align existing entities to a known position or to scan directly in a new co-ordinate system. In the KUBE software there are defined seven methods of creating transformations:

  1. Interactive - interactive method to set transformation using planes, lines, and points. Not all three correspondences are necessary to be defined in order to create a transformation.

  2. From 3 Entities - interactive method, where can be used all available primitives to set transformation

  3. From N constrained points - interactive method to set transformation by using N points, where each point can be point, circle centre or sphere centre.

  4. From N Points - non-interactive method to set transformation by using N points.

  5. 3-2-1 - non interactive method to set transformation using planes, lines and points.

  6. From Viewport - generates transformation from the current view.

  7. From Single plane - non interactive method to set transformation by single plane correspondence.

  8. Type In direct input of the rotation/translation parameters or the transformation matrix.

There exists a special entity in the Entities tree Current CS: It shows the transformation that is currently active. Its values could be:

  1. World CS, which is the world co-ordinate system (or the co-ordinate system of the localiser).

  2. Name-Of-Transformation that is currently active.

When update Current CS with some transformation all entities are affected. The only exceptions are the entities that are marked as Locked.

Current CS entity and the Transformations group are hidden by default. This is because all transformations are represented in the viewport as icons (including Current CS, which is displayed with longer axes than the inactive transformations.) When calling Zoom All command all visible transformations are also used for calculating the zoom extents.
