Draw Polyline Nodes as Crosses

This command is accessible from the tree context menu for polylines > Draw Polyline Nodes as > Crosses.

Description: Draw Polyline Nodes as Crosses is available for polylines only. When you select it, all nodes of every polyline will be visualised as yellow crosses oriented to the polyline direction.

This command affects to all polyline groups in the active window although it was applied to a single polyline or polyline group. The other open windows are not influenced on it. The state of Draw Polyline Nodes as Crosses is not stored, i.e. next time when you open the file nodes will not be displayed.

Example

Crosses are not displayed if you select Polygons render mode from the viewport context menu.
