Inspection Interface

In Inspection mode the user has a lot of possibilities to customize previews and report results:

  • Change inspection settings - max distance, inspection method, point sampling;

  • Set comparison ranges and colour plot schemes;

  • Set different rendering for compared entity and reference;

  • Create 3D predefined and custom views and save them in report pages;

  • Create single and multiple 2D views and save them in report pages;

  • Create outlined pages;

  • Create, modify and customize labels;

  • Preview and customize grid in both 2D and 3D views;

  • Extract statistics for each report page;

  • Save a snapshot of inspection viewport in different formats;

  • Generate inspection report (fully customized settings, XML templates).

All above mentioned options are accessible in inspection mode using both inspection menu and inspection toolbar. The functionality and the interface design are described in the next sections:
