Inspection Toolbar

Here is a snapshot of the toolbar in Inspection mode and below are the explanations for each button function.

 

Button

Name

Description

Details

Profile settings

Displays settings of the current profile.

Listbox

Surface materials

Selects a profile from the list.

Save

Saves the current inspection and the active document in 3D Scanners format document - sab2 file.

Zoom window

Resets the view extents to fit the visible data in the rectangle that is drawn by the mouse.

Zoom mode

Zooms in or out depending on the mouse move up or down. The significant destination for the mouse move can be swapped in System > Preferences > Display > Rotate/Pan/Zoom dialog.

Rotate

Rotates the scene by the mouse. When this mode is enabled and you press the left mouse button on the viewable area, a dashed circle will appear. If mouse pointer is within this circle, the rotation is on all three axes; otherwise the rotation is clockwise or counter-clockwise towards the viewport.

Pan

Translates the scene by the mouse.

 

Edit labels mode

In this mode labels can be created, arranged, deleted etc.

Edit annotations mode

In this mode annotations can be created, modified and deleted.

Adjust section plane

Launches the Define cross section function used to create and edit section plane in the current view.

Align view to section plane

Used to display only points lying on the cutting plane.

Colour plot Settings

Allows to customise the colour plot scheme and splits.

More info

Provides additional statistics information.

Plot window

Displays the distribution of the point according to their distance to the reference mesh.

Save a snapshot

Captures the whole viewport and saves it as image file.

Generate report

Launches the wizard for report generation.

Hardware Settings

Displays Hardware Settings dialog. This dialog offer different options for each sensor model, as follows: MMZ -; MMX - ; MMD -; MMC -

 

Preferences

Displays Preferences dialog.

Exit

Exits the Inspection mode and returns to main edit mode.
