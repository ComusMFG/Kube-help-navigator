Scale Points

This command is accessible from Edit > Scale Points.

Description: Scale Points is applied to scan data, meshes, point clouds, probe points, and polylines. It scales the selection in X, Y, and/or Z directions of the local co-ordinate system. The command is grayed if there are no visible selections of the above data. Scale Points can be applied to whole entity as well as partial selection.

Scale along X

Scale factor along X-axis.

Scale along Y

Scale factor along Y-axis.

Scale along Z

Scale factor along Z-axis.

Use centre of gravity

If checked the centre for scaling is the selection's centre of gravity, otherwise the centre is the origin of the current co-ordinate system.

Examples

Use centre of gravity

Do not use centre of gravity

Scale factor of 1 will not scale the selection at the corresponding direction. Scale factors between 0 and 1 will decrease the selection at the corresponding direction. For example, if X = 0.2, this means that the object will be reduced 5 times at X-axis (0.2 = 1/5). Scale factors greater than 1 will increase the selection at the corresponding direction. For example, if Z = 5, this means that the object will be enlarged 5 times at Z-axis. Zero values are not allowed. Negative values are used to mirror (and eventually scale) objects.

Note: Using scale factors of -1 lets the user to mirror the selection.

Examples

Original object

Object scaled 2 times along X-axis (X=2, Y=1, Z=1)

Object scaled 2 times along Z-axis (X=1, Y=1, Z=2)

Object mirrored along X-axis (X=-1, Y=1, Z=1)

Use Scale Points command to scale and/or mirror objects along the co-ordinate system axes.
