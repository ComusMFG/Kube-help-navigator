Rotate

This command is accessible from the viewport context menu > Rotate, by pressing Shift + R, or by pressing Rotate button on the toolbar.

Description: When this mode is enabled and you hold down the left mouse button on the viewable area, a dashed circle will appear. If mouse pointer is within this circle, the viewpoint rotation is on all three axes; otherwise it is clockwise or counter-clockwise towards the viewport.

Mouse pointer in Rotate mode within the circle

Mouse pointer in Rotate mode outside the circle

Exit Rotate mode by switching to another one Zoom Window, Zoom Mode, or Pan. This mode is not stored so when you open another window, Zoom Window mode will be enabled.

Example

Note: Using Shift + Left mouse button or only Right mouse button it will always switch to Rotate mode. When the mouse button is released, KUBE will switch to the previous mode. When in Rotate mode manipulations with the mouse are infinite. This means that if the mouse cursor exit from the screen it automatically appears at the opposite side of the screen if the mouse continue in the same direction.
