Construct_Transformation_321

Description: Creates new transformation from a plane reducible entity, a line reducible entity, and a point reducible entity.

Parameters:

Name name of the resulting transformation that will be created.

Plane name of the construction plane reducible entity. Could have entity of one of the following types:

  • Plane uses the plane itself.

  • Circle uses the circle plane.

  • Cylinder uses its first base plane (if PlaneIndex = 1) or second base plane (if PlaneIndex = 2).

  • Cone uses its base plane.

  • Rectangular slot uses slot plane.

  • Round slot uses slot plane.

CoordFrame defines the co-ordinate frame for the plane. Available values are: oXY, oYZ, and oXZ.

Line name of the construction line reducible entity. Could have entity of one of the following types:

  • Line uses the line itself.

  • Cylinder uses its axis.

  • Cone uses its axis.

  • Rectangular slot in this case uses one of its sides. LineIndex is used to determine the side.

  • Round slot uses its axis, i.e. the full length of the slot.

Axis defines the axis for the line. Available values are: +oX, -oX, +oY, -oY, +oZ, and-oZ.

Origin name of the construction point reducible entity. Could have entity of one of the following types:

  • Point uses the point itself.

  • Line uses first (if PointIndex = 1) or last (if PointIndex = 2) point from the line.

  • Plane uses its centre point.

  • Circle uses its centre.

  • Sphere uses its centre.

  • Cylinder uses first (if PointIndex = 1) or last (if PointIndex = 2) point from its axis.

  • Cone uses its apex (if PointIndex = 1) or base centre (if PointIndex = 2).

  • Rectangular slot uses its centre (if PointIndex = 0), its first corner point (if PointIndex = 1), its second corner point (if PointIndex = 2), its third corner point (if PointIndex = 3), or its fourth corner point (if PointIndex = 4).

  • Round slot uses its centre (if PointIndex = 0), its first semicircle centre (if PointIndex = 1), or its second semicircle centre (if PointIndex = 2).

Project determines whether the point should be projected to the plane or the plane should be offset to the point. Available values are Yes and No.

PlaneIndex used only if the entity in Plane parameter is cylinder. In this case the values are 1 or 2. In all other cases this parameter is ignored. Default value is 0.

LineIndex used only if the entity in Line parameter is rectangular slot. The values are 1, 2, 3, or 4, which means the side of the slot. In all other cases this parameter is ignored. Default value is 0.

PointIndex used only if the entity in Origin parameter is line, cylinder, cone, rectangular slot, or round slot. The values are 1 or 2 for line, cylinder, cone, 0, 1, 2, 3, or 4 for rectangular slot and 0, 1, 2 for round slot. In all other cases this parameter is ignored. Default value is 0.

UI Commands:

Transformations > 3-2-1 from the main menu.

Example:

Construct_Transformation_321( Name="Transformation 1", Plane="Plane 1", CoordFrame="oXY", Line="Line 1", Axis="+oX", Origin="Point 1", Project=Yes, PlaneIndex=0, LineIndex=0, PointIndex=0 )
