On Rotate/Pan Draw Scene

This command is accessible from the viewport context menu > On Rotate/Pan > Draw Scene or by selecting Scene option in System > Preferences / Display / Rotate/Pan/Zoom dialog.

Description: On Rotate/Pan Draw Scene command affects visualisation of scan data and meshes in the scene during rotate, pan, and zoom actions and is related to the appearance of objects. Selecting this command will cause KUBE to display objects in their current rendering mode during rotate, pan, and zoom. For example, if render mode is Smooth Shaded, meshes and scan data will be rendered in this way.

This command is equivalent to the Scene option in Draw group from Preferences / Display dialog. This mode is not stored so next time when you run KUBE Draw Points will be used.

Example

Object during rotate, Scene render mode Smooth Shaded current render mode

 

Note: On Rotate/Pan Display Custom, Less, Normal, and More commands are not used when you are in Draw Scene mode.
