From N Points

This command is accessible from Transformations > From N Points.

Description: Transformation From N Points command creates a transformation constructed from a set of known points. The name of the entity is System from points N, where N is the number of the subsequent newly created datum alignment.

  • Use the two drop down lists to enter corresponding datum points or point reducible entities.

  • Add button add the point pair.

  • Remove button remove the point pair.

  • Transformation matrix the matrix that transforms points from one transformation to the other.

  • Transformation RMS indicates the error of the mapping between the two sets of points.

The sequence to create transformation is as follows:

1. From the left hand list select a source point.

2. From the right hand list select the corresponding target point.

3. Press Add button to add the pair of points.

  • In case of error, i.e. a pair does not contain corresponding points select this pair from the list of added pairs and press Remove button to remove it.

  • After the third pair a matrix of transformation and RMS error is displayed.

4. Repeat steps 1 3 to add all pairs of points.

5. Press OK button to create the transformation.

Transformation schematic

Note: You have to add at least three pairs of corresponding points in order to generate transformation.

Generate Co-ordinate System From N points method is used when aligning two separate data sets sphere-to-sphere alignment and point-to-point alignment.
