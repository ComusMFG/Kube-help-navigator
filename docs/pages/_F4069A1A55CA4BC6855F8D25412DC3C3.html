Preferences - Display - Grid

The options in this group are related to visualisation of the grid lines.

Minor Lines group

Spacing

Specifies the distance between two minor grid lines. Default value is 10mm.

Width

Specifies the thickness of the minor grid lines. Default value is 1 pixel.

Show values

Check this box in order the minor grid line values to be displayed.

Font size

Font size for the minor grid line values. Default value is 8 pts.

Major Lines Group

Display

Check this box to display the major grid lines when grid lines are displayed by calling Display Grid command.

Every ... lines -

Specifies how many minor grid lines will be displayed between two major grid lines. Default value is 10 lines.

Width

Specifies the thickness of the major grid lines. Default value is 2 pixels.

Show values

Check this box in order the major grid line values to be displayed.

Font size

Font size for the major grid line values. Default value is 8 pts.

 

Opacity slider

Sets the transparency of the grid lines. Moving the slider to left makes the grid lines more transparent.
