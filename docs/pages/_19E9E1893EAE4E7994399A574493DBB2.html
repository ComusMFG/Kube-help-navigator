Sphere Alignment Procedure

Description: Alignment Procedure specifies how to do alignment.

First steps

    • Ensure the localiser hardware and software setup is complete

    • Run KUBE

    • Leave the sensor switched on for 30 minutes before starting the alignment procedure.

Note: This is not applied to MM D and newer sensors

    • Ensure the Laser power is set to its default value (Hardware settings\Sensor tab\Laser power).

    • Enable the option Display Command window in View menu or by pressing F11 functional key

Note: at this stage the sphere alignment procedure can be started by macro command only (no menu item or toolbar icon available).

You are ready now to follow the alignment wizard

Alignment wizard (Manual Qualification)

  1. Type the command DoSphereQualification() with correct parameters in the KUBE command line to start alignment procedure.

  2. Confirm the appearing message to initialise the qualification:

Alignment procedure includes capturing patches on the sphere

  1. in 3 directions (approx 90 degrees between them)

  • and in 4 quadrants for each direction (near left "quadrant 1" , near right "quadrant 2", distant right "quadrant 3" and distant left "quadrant 4"), as displayed on the pictures below (direction 1)

  1. Point the sensor to fit the laser stripe to the sphere diameter (1st  position, 1st quadrant). In KUBE the laser stripe should lie on the circle drawn in the view window as shown on the picture below.

  1. Hold the sensor firmly and scan a patch by pressing B button

  2. The stripe counter starts increasing the number of captured stripes. When this number exceeds 12, the current quadrant and the stripes number will be coloured in green. The patch is captured successfully.

  3. If the scan is successful then ignore the Remove last patch message by pressing B button again. If you need to repeat the same scan, then confirm the Remove last patch message and capture the data once again.

  4. Follow steps 4 to 6 for the 4 quadrants in all 3 directions.

  5. Next step is to capture 4 Velocity scans in one scanner orientation.To take into account the motion of the scanner at the highest used velocity, some scans are made. The laser stripe is pointed to the sphere diameter and is moved in the direction of the laser plane:

    1. from position 1 (quadrant 1 or closer to the scanner) to 4 (quadrant 4 or further from the scanner) and back at high speed, i.e 2 velocity scans captured

    1. from position 2 (quadrant 2 or closer to the scanner) to 3 (quadrant 3 or further from the scanner) and back at high speed, i.e 2 more velocity scans captured

  8. When 16 successful patches are measured, the Finish button becomes available

  1. At this stage there are 2 possibilities: some additional patches can be taken (no limit for orientation, number or speed), or the sphere alignment can be calculated.

  2. Press the "Finish" button to end the capture wizard, then confirm the appearing message to calculate the sphere qualification.

  3. When the alignment is calculated, results will be displayed in a window.

  4. If the std dev and condition number values are below warning level values, the qualification will be accepted and saved.

Note: If no name has been set, you will be prompted for alignment name

  1. If  the std dev or condition number values are in the warning level ranges, a warning message will appear asking whether to accept or reject the alignment.

  2. If the std dev or condition number values are above the error level, the sphere qualification will be automatically rejected.

Although the results screen can indicate whether the alignment has been successful, it is necessary to perform a system certification check to certify performance.

 

Alignment wizard (Teaching Robot)

  1. Type the command DoSphereQualification() with correct parameters in the COM interface command line to start alignment procedure.
    Alignment procedure includes capturing patches on the sphere

    • in 3 directions (approx 90 degrees between them)

    • and in 4 quadrants for each direction (near left "quadrant 1" , near right "quadrant 2", distant right "quadrant 3" and distant left "quadrant 4"), as displayed on the picture for direction 1 in the previous section

  4. The scanner starts measuring the laser line in order to feedback the reflection of the laser line on the sphere in the GUI . The robot programmer moves the RoboScan to the sphere and tries to fit the laser line onto the ideal sphere that is visible in the GUI. Thus projecting the laser line on the largest diameter of the physical sphere.

  5. If the fit is sufficient, the robot programmer moves the robot perpendicular to the laser plane

    • to the beginning of the sphere with and additional 10 mm and saves this point in the robot. This is the "start point" (see picture below)

       

    • to the end of the sphere width additional 10 mm and saves this point in the robot. This is the "End Point" (see picture above)

  8. The robot programmer now replays this scan path while measuring data

    • move robot to start point

    • press "start patch" in Kube GUI

    • start robot motion until it stops

    • press "stop patch" in Kube GUI
      the patch is verified and the programmer receives an OK/green lamp for this patch.

  13. Steps 3 and 4 are repeated 3 more times to complete the 4 quadrants

  14. Steps 3, 4 and 5 are repeated completely 2 more times to complete the 3 orientations of the scanner.

  15. Next step is to take velocity scans
    The RoboScan is moved in order that the sphere moves in the FOV in the direction of the laser plane, 

    • from position 1 (or closer to the scanner) to 4 (or further from the scanner) and back at high speed

    • from position 2 (or closer to the scanner) to 3 (or further from the scanner) and back at high speed
      This leads to 4 additional scan patches

  18. After the 16th patch there is a possibility to capture as many patches as necessary (additional patches). At this stage the alignment can be calculated

  19. Type ScanCalculate() in the COM interface command line to get alignment results.

  20. The alignment results are shown in the COM interface window. If the std dev and condition number values are below warning level values, the qualification will be accepted and saved.

    • If the std dev or condition number values are in the warning level ranges, the qualification will be accepted or rejected depending on the AcceptAboveWarningLevel value.

    • If the std dev or condition number values are above the error level, the sphere qualification will be automatically rejected.

  22. The robot programmer now edits the robot path program by inserting the correct RoboScan commands.

  23. The complete qualification with robot commands is tested.
