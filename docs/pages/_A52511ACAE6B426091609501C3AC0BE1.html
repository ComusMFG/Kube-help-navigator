Align View to Plane

This command is accessible from 2D Sections > Align View to Plane or by pressing Align View to Section Plane button in the Inspection toolbar.

Description:

This command displays the compared object in 2 dimensions at the place where the defined section plane passes through it. The resulting 2D section will be automatically zoomed all to the viewport. The Align View to Plane command is grayed if there is no section plane defined for the current report page.

Example

3d view of the compared object with a section plane defined in the current report page

Same object in Aligned view to the section plane

Note: 2D section view will be kept during the following operations: zoom, translate and rotate around the Z axis of the viewport. If rotation by 3 axis is used, then the 2D section view will be transformed to 3D view of the compared object and the section plane.
