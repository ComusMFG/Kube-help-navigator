Capture Cone

Description: Capture Cone allows a datum cone to be captured using the localiser probe or to be extracted by scanning using the sensor. It can be used to measure conical objects. This command is accessible from the LocaliserMenu Datum > Cone.

Wizard

When you select Datum > Cone from the localiser menu the wizard behaves depending on the settings in System > Preferences > Datums > Capture Method (Datum Capture Method) dialog. If Cone listbox is set to Prompt the following dialogue will appear:

At this stage there are offered 2 possibilities for measuring the cone:

  • If you selectTactile, you will capture the cone using the localiser probe. See Capture Cone Wizard.

  • If you select Scanning, you will scan the cone using the sensor. See Scan Cone Wizard.

 

Capture Cone Wizard

When Tactile is selected, the following dialogue will appear:

  • Press 'B' button consecutively to collect the necessary points. Hold 'B' button to delete the last captured point if necessary. Press 'A' button to finish.

If Tolerance check is enabled and the next point is out-of-tolerance KUBE will play warning sound and will display out-of-tolerance value in yellow. See System > Preferences > Datums > Form Tolerances for details.

Sometimes a cone cannot be created due to lack of points or irregular distribution of the captured points. In this case a warning message will appear.

  • Select the side of the cone ('A' - inner side or 'B' - outer side)  from which the points were captured.

If the ball probe is used, it will inflate or deflate the cone with the radius of the probe depending on which side was captured. This is very important for the correct cone diameter because every localiser returns co-ordinates of the centre of its probe. See Offset On Curved Surfaces for details.

KUBE will fit a cone from the set of the captured points. The information about the radius (diameter) of the resulting cone and the RMS of the fitting will be displayed:

Example

  • Press 'A' button to reject the resulting cone or 'B' button to create it.

After finishing the capture procedure, KUBE will issue a dialog, asking you if you will continue capturing cones.

Example

  • Press 'A' button to exit the capture mode or 'B' button to continue capturing using Tactile method.

 

Scan Cone Wizard

When Scanning is selected, an additional window (which displays the scanned data) will pop-up and the following dialogue will appear:

  • Press 'B' button to start scanning. Scanning is performed as in the normal Scan mode, i.e. after you press 'B' button KUBE starts capturing a patch and after you press it again KUBE will stop scanning and will enter in Pause mode.

Example

  • When done with the scanning press 'A' button to exit. If the extraction is successful you will get information about the radius (diameter) of the resulting cone and the RMS of the extraction.

Note: Cone detection is controlled by Tolerance parameter. See System > Preferences > Datums > Detection Tolerances for details.

Example

  • Press 'A' button to reject the resulting cone or 'B' button to create it.

After finishing the scan procedure, KUBE will issue a dialog, asking you if you will continue scanning cones.

Example

  • Press 'A' button to exit the capture mode or 'B' button to continue capturing using Scanning method.
