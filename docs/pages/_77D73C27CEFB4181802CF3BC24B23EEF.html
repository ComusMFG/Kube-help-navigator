Localiser Menu Settings

This command is accessible from System > Localiser Menu Operation > Settings.

Description: The Localiser menu Operation - Settings command invokes the dialog from where you can tune up different localiser menu settings.

Call the function and a the following dialog will appear:

Menu activation button group:

Any - select this option to activate commands from the localiser driven menu using A or B buttons.

A - select this option to activate commands from the localiser driven menu using A button. This is the default mode.

B - select this option to activate commands from the localiser driven menu using B button.

These options are valid for selecting the commands from the menu only. They do not override the buttons for the subsequent actions of the particular commands. For example, if the 'Any' option is selected you can enter Scan mode by both A or B buttons, but then you can scan/pause by B button only, and exit this mode by A button only.

Localiser movement sensitivity slider

Used for setting the localiser movement sensitivity over the Scan pane. Moving left means less sensitivity, moving right means more sensitivity.
