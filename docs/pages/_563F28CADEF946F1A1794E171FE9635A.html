Hardware Settings

Description: Hardware Settings allows most of the settings in a profile to be saved and is used to achieve the best performance. Custom Settings allows the user to configure KUBE for a certain type of object and save those settings for future use. This command is accessible from the System > Hardware Settings or by pressing the Hardware settings button on the toolbar

Hardware Settings window is divided in nine tabs related to different parts of the system and different stages of the scanning procedure.

  •  Click on each Tab title to follow its description.
