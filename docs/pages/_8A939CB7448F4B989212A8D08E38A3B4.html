Comparison

This command is accessible from:

1. Main edit mode - 3D Inspection > Comparison command or by pressing the 3D comparison button on the toolbar.

2. Inspection mode - Settings > Inspection command.

Description:

Comparison function is the start point of a new session for the Inspection process when called from main edit mode or changes inspection parameters (Max distance, inspection method, and point sampling) when called from Inspection mode.

Use: It is used for online as well as for offline inspection, i.e.:

1. Online - only a reference (CAD model or datum entity) is needed and Current CS should be registered to that reference. When enter Inspection mode KUBE us ready to scan. Every patch is immediately coloured depending on the selected settings.

2. Offline - the scene contains previously scanned data and now user needs to compare it to a CAD model, for example. Before starting the inspection process both surfaces (model and inspected) must be properly registered or there must be proper transformation activated for scanning.

Note: If you don't have a visible reference entity, then the function will be disabled.

Go to 3D Inspection > Comparison to invoke the 3D Comparison Settings dialog. This function inspects a selection or a whole selected entity using reference mesh or datum entity. If no selection is made it can be done within the dialog - simply choose one or more entities to compare and confirm.

Notes:  If no entity is selected for inspection KUBE will do online inspection.

 

Input parameters section

Dialog when called from main edit mode (Entities and Reference lists are enabled).

Note: All inspection entities could be removed from the Entity section, if necessary. In this case Instant inspection only can be performed in Inspection mode.

Dialog when called from Inspection mode (Entities and Reference lists are disabled)

 

Reference section

Select the entity to be used as a reference for comparison. Reference entities can be mesh, point, line, circle, plane, cylinder and sphere. Only visible entities will be available as reference entities. If no entities are available in the list, check if you have not selected all entities available or all entities are hidden. If there is Inspection mode saved in this file, its reference entity will be displayed by default. When this dialog is called via Settings > Inspection command this listbox is grayed, i.e. in Inspection mode user cannot change the reference.

Distance section

Sets the maximum distance for comparison and the comparison method.

Maximum distance - no points from the inspection surface, that are further apart from the reference surface, beyond the value in that field, are compared.

Method - to select the method for calculating the distance from the inspected points to the reference surface. The available methods are:

    1. Normal to surface (Default) - the distance is a normal to the reference surface, i.e. orthogonal to it (distance is D).

    2. Along Ox - the distance is projected to Ox axis (distance is Dx).

    3. Along Oy - the distance is projected to Oy axis (distance is Dy).

    4. Along Oz - the distance is projected to Oz axis (distance is Dz).

Point sampling section

When having big meshes, it is not necessary to compare each their point. Sufficiency of information we can get even if we compare every third or second point of them. But in this case we may have significant improvement of comparison speed. That's why KUBE provides point sampling mechanism.

Use % of the points select this if you want manually to define how many points to be used in inspection process. Leave this value to 100% and each point will be compared.

Auto sample KUBE will determinate the optimal number of points to be compared in order to get the maximum comparison speed while keeping the same quality.

Overwrite existing values section

Sets whether to use the following parameters from the previous inspection (if there is one) or to use new values. If these is previous inspection this options will be disabled.

Reference select a display mode for the reference entity. Six modes are available:

    • None does not display the reference at all.

    • Boundary displays the reference as boundary. This option is available only for pages aligned to cross sections.

    • Flat displays the reference in flat shaded mode.

    • Smooth displays the reference in smooth shaded mode.

    • Flat and transparent displays the reference in flat shaded mode with transparency.

    • Smooth and transparent displays the reference in smooth shaded mode with transparency.

Note: The transparency for the last two modes is controlled from System > Preferences > General tab - Inspection mode rendering group.

Ranges the next options define the range of the colour scale and the zero range - all points within this range will be coloured as zero points.

    • Max - the upper border of the colour scale. All points, higher than this value will be coloured as Above Max values.

    • Min - the lower border of the colour scale. All points, lower than this value will be coloured as Below Min values.

    • Max Zero - the upper border of the zero range.

    • Min Zero - the lower border of the zero range.

    • Note: The minus sign for the Min values in this section is not taken for granted, so you need to type it if you mean it.

When ready with the inspection settings, click on the OK button to enter the Inspection mode:

The comparison process can take a few minutes if the inspected entities are big. When it ends you will get the results in coloured error map. This means that the Inspection mode is started.

Note: When enter Inspection mode the default colour setting is discrete. Default Min and Max values equal to the range divided by the number of sections of colour plot.
