FARO Localiser Set-up

Handling Your Localiser

The localiser is a precision measuring instrument, please treat it with care.

The localiser has been designed to withstand a typical shop-floor environment, nevertheless, please ensure that it is handled with care according to the manufacturers instructions.

 

FARO Arm BIOS

KUBE will only scan correctly with the following BIOS versions:

  • BIOS 7.20 - Gold arm (front option port only)

  • BIOS 7.31/7.61 - Gold arm (front and rear option port)

  • BIOS 4.82 - Silver arm

  • BIOS 7.20 - Sterling arm

The FARO Gold arm BIOS is not compatible with FARO Silver arm and vice versa.
