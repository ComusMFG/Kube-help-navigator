Fit Circle

This command is accessible from Measure > Geometry > Circle or by pressing Alt + 6.

Description:Fit Circle command fits a datum circle to the visible selection, which may include scan data, meshes, point clouds, datum points and polylines. This command is grayed if there is no selection or all selections are hidden.

Note: If needed to fit circle to existing datums, you should use datum points only. Including other datums in the selection will lead to incorrect results.

Call the Fit Circle command and the following dialog will be displayed:

 

Deviation

  • Max/Min value: Maximum deviations from the outer and inner sides of the fitted circle.

Select plane

  • Plane selection drop-down list: The points of the circle must first be projected onto a plane entity. The plane entity can be selected from the drop-down list or it will be fitted to the selected points.

  • Use boundary points only: Use only the boundary points to fit the circle. This option can be applied to mesh entities only.

  • Fixed radius: Enter a predefined radius for the circle to be detected.

The dialog includes also the following statistics:

Centre

  • X, Y, Z co-ordinates of the centre of the fitted circle.

Statistics

  • Radius: the radius calculated from the selected data.

  • RMS error: Root Mean Square of the selected data points from the calculated circle.

Buttons

  • Recalculate: fits a circle again according to the current deviations.

  • Create circle: creates a datum circle entity from the fit data.

  • Plot: calls the error distribution plot dialog.

  • Close: exits this mode.
