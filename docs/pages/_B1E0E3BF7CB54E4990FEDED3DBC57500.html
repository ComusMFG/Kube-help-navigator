Export

This command is accessible from File > Export.

Description: The Export command converts data from the current document to different file formats.

Mark a whole entity (or  many entities) in the Entity Pane Entities pane is one of the three panes located in the left hand side of the KUBE window. All these panes are overlapped and you can switch between them by clicking on their tabs (which are in the lower left hand side) or by shortcuts (Ctrl + 1 for Scan pane, Ctrl + 2 for Entities pane, Ctrl + 3 for Output pane). or use selection functions to make a selection in the currently opened KUBE document. Call the Export command and choose the appropriate format from the drop-down list. Browse to choose a target folder and confirm the operation.

Note: The dimensions of the exported entities are calculated according to the currently selected Units in KUBE.
