Bind Views - Relative

This command is accessible from Windows > Bind Views > Relative.

Open two or more documents and tile them horizontally or vertically.

Description: When enabled Bind Views - Relative will cause all open windows to display the same visible region and to update all views simultaneously according to the active window. This means that all commands (Zoom, Rotate, Pan, change light direction, etc.) applied to the active window will have the same effect on all other windows in their extents at the time this mode was enabled.

This command is applicable for different documents. When this mode is enabled the command is marked with a tick and a jagged chain icon appears at the top left corner of every window:

Call Bind Views - None to disable it. The state of Bind Views - Relative is not stored so next time when you run KUBE will be disabled.

Bind Views - Relative is useful when you want to compare two or more objects (in different documents) that are further apart from each other and not equally oriented.
