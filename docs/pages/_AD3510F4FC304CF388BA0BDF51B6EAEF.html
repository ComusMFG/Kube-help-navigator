Invert Selection

This command is accessible from Select > Invert, by pressing Invert selection button on the toolbar or by using the shortcut Crtl + I.

Description: Invert Selection selects all visible unselected entities (or parts of them) and deselects all visible selected entities (or parts of them).

This command is mainly used when you want to select most of the entities in the scene and leave unselected small number of them. Then select only these that you want to remain unselected and apply Invert Selection. Another usage is when you want to select huge part of an object and leave small area (or areas) unselected select this small area (or areas) and apply Invert Selection.
