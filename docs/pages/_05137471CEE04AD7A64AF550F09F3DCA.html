Settings Menu

The Settings menu contains 2 commands:

 

Command

Description

Details

Colour Plot

Displays Colour Plot Settings dialog.

Inspection

Displays 3D Comparison Settings dialog.

Note: When this dialog is called from Inspection mode the inspected data and the reference cannot be changed (Reference list is disabled). User can only use it to recalculate current inspection using new Max distance, inspection method, and point sampling.
