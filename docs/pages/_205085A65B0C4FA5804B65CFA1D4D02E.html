ModelMaker Y/Z Installation Troubleshooting

How to check for problems

  • Right-click on My Computer icon and select Manage. Click on Device Manager from the left pane in the Computer Management window. Expand System devices from the right pane. If "DEC 21150 PCI to PCI bridge" device is displayed with exclamation mark then you should check for the error code.

  • Right-click on "DEC 21150 PCI to PCI bridge"device and select Properties. Error code can be found in the Device status field from the General tab.

Laptop PC installation

  • If there is an error code 31 for "DEC 21150 PCI to PCI bridge" in Windows Device Manager and SURFA PCI devices do not present in the list it is recommended to move PCMCIA card to the other PCMCIA slot. After that Windows will ask to restart. If still KUBE cannot detect the MMIB then repeat the procedure and check the error code again.

  • If there is an error code 12 for "DEC 21150 PCI to PCI bridge" in Windows Device Manager and SURFA PCI devices do not present in the list it is recommended to install PCMCIA device drivers from installation CD.

  • If still KUBE cannot detect the MMIB-DL then repeat the procedure and check the devices. This time there should not have to be a problem with "DEC 21150 PCI to PCI bridge" (which must appear as two devices).
    Expand "SURFA PCI Boards" and check whether some or all of its sub-devices ("SURFA PCI2 Video Component" and/or "SURFA PCI2 Audio Component") are displayed with exclamation mark. If so, check the error code in the same way as checked for "DEC 21150 PCI to PCI bridge" device.
    If the reported code is 12 then it is recommended to use CbRegEdit.exe utility that is installed along with PCMCIA card drivers to set PreFetch and Memory values to 10000. Utility can be found in C:\Program Files\Magma. or it can be directly started from Start > All Programs > KUBE vXX > KUBE Tools > MMIB-DL (Magma) Settings.

 

Desktop PC installation

  • If there is an error code 12 for "DEC 21150 PCI to PCI bridge" in Windows Device Manager it is recommended to update system PC BIOS up to the latest version provided by PC or mainboard manufacturer.

  • If still KUBE cannot detect the MMIB-DL then repeat the procedure and check the devices. This time there should not have to be a problem with "DEC 21150 PCI to PCI bridge" (which must appear as two devices).
    Expand "SURFA PCI Boards" and check whether some or all of its sub-devices ("SURFA PCI2 Video Component" and/or "SURFA PCI2 Audio Component") are displayed with exclamation mark. If so, check the error code - in the same way as checked for "DEC 21150 PCI to PCI bridge" device.
    If the reported code is 1 then it is recommended to uninstall and install again KUBE.
