Median Noise Reduction

This command is accessible from Scan Data > Reduce Noise > Median.

Description: Median Noise Reduction command reduces noise by applying a median filter on each stripe. Spikes and isolated peaks in the data will be removed but critical features will be preserved.

This command modifies the selection by removing outlying (noisy) data. This command is grayed if there is no selection or all selections are hidden. It works on wholly selected entities as well as on partial selection.

Median filter size

Specifies the area over which filter operates. It ranges from 1 to 10. Default filter size is 1.

Poor surface finish, direct reflections or using incorrect laser power setting may cause noise in the data.

Use Median Noise Reduction to remove any outlying (noisy) data in the scan.
