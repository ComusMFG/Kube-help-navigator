On Rotate/Pan Display More

This command is accessible from the viewport context menu > On Rotate/Pan > Display More or by setting the More option in System > Preferences / Display / Rotate/Pan/Zoom dialog.

Description: On Rotate/Pan Display More command affects visualisation of scan data, meshes, and point clouds in the scene during rotate, pan, and zoom actions and is related to the details of objects.

It is not applicable when On Rotate/Pan Draw Scene is enabled. Selecting this command will cause KUBE to display every point during rotate, pan, and zoom. It is equivalent to the More option located in Number of points group from Preferences / Display dialog. This mode is stored so next time when you run KUBE Display More will be used.

Use this command for simple objects in order to see more details.
