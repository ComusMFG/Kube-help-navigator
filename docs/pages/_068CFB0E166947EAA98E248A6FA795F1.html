Scanning Strategy

Sensor Handling

  • Do not block the optical path of the laser or CCD sensor to the object. ModelMaker is a delicate and valuable instrument and should be treated like one.

  • Make sure you do not touch the optical windows on the front of the sensor.

  • The cover on the ModelMaker sensor should never be removed.

  • Laser light is emitted from the aperture in the centre of the sensor. Never look into the laser aperture.

Sometimes the laser will remain active when a scanning operation is completed. Select this button to turn the laser on or off.  

 

Localiser Handling

When setting up the ModelMaker system to perform a scanning job, first check that the localiser and sensor geometry allows you access all areas of the part. To do this, perform a quick dry run with no scanning to ensure:

  • That you can scan the sensor at the nearest point of the object to the arm base. 

  • That you can scan at the furthest point of the object from the arm base If you are capturing datum points from the part, check that the probe has access to these points.

  • If you are using datum cones, for example for scanning a whole car, it is recommended to perform a dry run to ensure the layout is correct for the size of object.

When positioning an arm, look to avoid:

  • Collisions between arm and object. 

  • Not being able to reach to scan all parts of object.

  • Arm reaching the end of travel of one of its joints.
