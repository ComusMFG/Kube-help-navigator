Auto Extract Circle 

This command is accessible from Datuming> Auto Extract> Circle or by pressing Ctrl + Alt + 6.

Description: Auto Extract Circle command fits and creates datum circles to the visible mesh selections. This command is grayed if there is no mesh selection or all selections are hidden.

Call the Auto Extract Circle command and the following dialog will appear:

Type group

  • All circles -Tries to extract both internal and external circles. This option is by default. Use this option if you want to extract all types of circles or it is not clear what is the type of the circle.

  • Internal circles only -Extracts internal circles only. This means that the function will try to extract circles on planes with holes.

Example

  • External circles only - Extracts outer circles only. This means that the function will extract circles on planes that have circular shape.

Example

Circles with fixed radius group

Enable this option to extract only circles having radius that varies from Radius Tolerance up to Radius + Tolerance.

  • Radius - Radius of the extracted circles. Default value is 5mm.

  • Tolerance - Tolerance of the radius. Default value is 0.5mm.

Circle Acceptance RMS

RMS threshold when fitting circles. Decrease this value to extract circles from more circular shapes and vice versa. Default value is 0.1mm.

Flatness Acceptance RMS

RMS threshold for the flatness of the fitted shape. Decrease this value to extract circles from flattish shapes and vice versa. Default value is 0.21mm.

Use only boundaries with min N points

Extracts circles from contours having more than N number of points. Use this option to prevent circle extraction from very small holes or floating meshes, which may have round-like shape but actually are not circles. For example, areas of missing points (due to scanning, sampling, or merging) or areas that represents regular polygons (squares, pentagons, hexagons, etc.)

Example

In contrast to the Circle Fit where all selected points are used, Auto Extract Circle uses only the part or all of the contour points of the selection when finding the fitted circle. This is why when using the Circle Fit command you have to select only the area containing the circular shape that has to be fitted. As closer to the contour is the selection, as more precise the circle fit will be. There is no such need when using Auto Extract Circle simply select the whole entity (or entities) and tune the parameters.

Use Auto Extract Circle to extract all circles from a mesh selection at once. It is very useful when import IGES files into KUBE.
