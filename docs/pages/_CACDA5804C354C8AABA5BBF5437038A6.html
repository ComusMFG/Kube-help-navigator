On Rotate/Pan Draw Shaded Points

This command is accessible from the viewport context menu > On Rotate/Pan > Draw Shaded Points or by selecting Shaded points option in System > Preferences / Display / Rotate/Pan/Zoom dialog.

Description: On Rotate/Pan Draw Shaded Points command affects visualisation of scan data and meshes in the scene during rotate, pan, and zoom actions and is related to the appearance of objects. Selecting this command will cause KUBE to display objects as large shaded points during rotate, pan, and zoom.

Note that these points are larger than the points in Large Points render mode. If the vertices are too close to each other in the current view, this mode looks similar to Draw Scene mode.

Number of displayed points depends on what command is selected (Custom, Less, Normal, More) and the settings from Preferences / Display dialog. This command is equivalent to the Shaded points option in Draw group from Preferences / Display / Rotate/Pan/Zoom dialog. This mode is not stored so next time when you run KUBE Draw Points will be used.
