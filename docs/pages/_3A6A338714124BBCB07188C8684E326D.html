New Sphere

This command is accessible from Datuming > Sphere, by using the shortcut Shift + Alt + 4 or by choosing the Circle tab in the Datum creation mode (if it is currently active).

Description: New Sphere command creates new datum sphere by one of the 2 available methods. Here below these methods are explained followed by examples.

Methods:

Interactive

: standard sphere construction using one of the available 4 definition methods (pick from viewport is enabled by default). For more details about the define section, see Define Sphere.

Example (using pick points method)

 

Circle and centre offset

: This method includes definition of a construction circle and input of parameter for centre offset. For more details about circle definition, see Define Circle.

How it works:

  1. The user defines a circle.

  2. The parameter for sphere centre offset can be set to any positive or negative value or left as 0.

    • If the sphere centre offset is left as 0, then the result sphere will have centre coordinates and radius identical to the construction circle

    • If the sphere centre offset is set to "+X mm", then the result sphere centre will be offset with X mm in direction of the circle normal. The sphere radius will be calculated as .

    • If the sphere centre offset is set to "-X mm", then the result sphere centre will be offset with X mm in direction opposite to the circle normal. The sphere radius will be calculated as .

Changes of all values can be applied at any time.
