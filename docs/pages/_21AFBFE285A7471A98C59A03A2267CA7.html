Polylines Description

Polylines are commonly used as a means of passing information to a CAD system for surface construction. Each polyline entity represents linear sequence of connected points in the 3D space called nodes.

Nodes of a polyline

Nodes in polylines are ordered thus there are two nodes that are connected with only one other node these are the first and the last nodes, defining the polyline direction. All other nodes are connected with two neighbours, which means that a polyline cannot contain isolated nodes.

Example for polylines extracted by cross sections from a mesh

All rendering modes are available for displaying polylines see Visualisation for details. When in Points or Large Points rendering modes, polylines are displayed as separate points. When in Polygons, Flat or Smooth Shaded rendering modes, polylines are displayed as sequences of connected lines.
