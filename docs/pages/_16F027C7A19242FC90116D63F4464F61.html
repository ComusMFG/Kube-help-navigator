Multi-Site Scanning Preparation

Before commencing with the multi site scanning process certain things must be done in preparation.

Items required

Several items will be needed to perform multi-site scanning. The following is a list of these items necessary for the scan:

  • Tripod mounted localiser

  • Set of floor-mount datum cones (supplied with all ModelMaker systems)

  • Recommended: arm counterbalance

  • Recommended: extension handle

  • Hot glue gun to mount the cones

  • Coloured insulating tape (50m) to mark out scanning box

  • String (5m) and chalk to mark up circular measuring extents of localiser

Location

It is essential to select the scanning location carefully in order to be able to scan effectively. The scanning location should have the following features:

  • convenient access so that the car can be driven in and out easily

  • there must be plenty of space around the car remaining for scanning

  • convenient access to a mains power supply

  • relatively constant temperature environment
